# Word sets and topic ladders

(Moved verbatim from CLAUDE.md on 2026-10-24; keep it up to date when changing these files.)

**Word sets (`data/vocab/*.json`, built by `tools/build_vocab.py`)**: the quiz, paths, flashcards and listening tool load bundled, graded word lists — `en_jh` / `en_sh` (大考中心 7000 Level 1–2 / 3–6), `en_toeic` (TSL), `en_toefl` (ECDICT toefl tag minus the 國中 words), `jlpt_n5`…`jlpt_n1` and `topik_1`…`topik_4` (the owner's own sheets; since 2026-10-10 the JLPT levels are checked against the tanos.co.uk lists (CC BY, `jlpt_reference()`): an entry the reference puts at an easier level moves there, a word in two levels stays only in the easiest, and a rarer reading of a common kanji (人 じん) or 1–2 unplaceable kana (だけ) goes to the end of its level — `JLPT_KEEP` / `JLPT_MOVE` hold the owner's overrides, and each run writes a review page, tools/.mockups/jlpt_moves.html), `hsk_1`…`hsk_7` (HSK 3.0, Nov-2025 revision; 7 = 7–9). Each list is ordered easy-first by frequency, which is what makes the first path levels easy. The **topic sets** `tp_<ja|ko|en|zh|fr|ru|es|de>_<topic>` (10 topics × 40 words = 4 levels each: greetings, food, home, shopping, transport, travel, weather, school, work, health; added 2026-10-04, French and Russian 2026-10-08, Spanish and German 2026-10-09 — French rows `le chat<TAB>m.<TAB>zh<TAB>en` and Spanish `el gato<TAB>m.<TAB>zh<TAB>en` (plurals as los / las) like the CEFR sets, Russian `слово<TAB>сло́во<TAB>zh<TAB>en`) are the exception: hand-written by Claude, approved by the owner, in `tools/topics/<lang>.tsv` (`## <topic>` headers, `word<TAB>reading<TAB>meaning<TAB>english`, edit those files directly) and kept in the file's order; `build_vocab.py --only topics` turns them into JSON. **French, Russian, Spanish and German** are graded by CEFR, A1–C1, on the 單字 page's 檢定等級 tab (`CEFR_LANGS`): `fr_a1`…`fr_c1` from FLELex (the "Beacco" version, which gives every lemma a level; replaced the owner's French sheet — `fr` is now in `LEGACY_SET_IDS`) and `ru_a1`…`ru_c1` from the Russian Kelly list, `es_a1`…`es_c1` from ELELex (per-level frequencies, not levels: a word's level is the first by which it has turned up in 2 texts; skip noise in `ES_SKIP`, the basic numbers are added by hand in `ES_NUMBERS`), `de_a1`…`de_c1` from DAFlex (same levelling; DAFlex has no genders, so gender and plural come from Wiktionary and German rows are `[der Hund, m. · Pl. Hunde, zh, en]`; feminine nominalised adjectives such as die Beste are dropped as duplicates, `DE_SKIP` / `DE_KEEP_FEM`). These lists lack translations, so `build_vocab.py --only fr|ru|es|de` (needs `pip install xlrd` for Kelly's .xls) streams Wiktionary's kaikki.org dump (≈0.6 / 0.9 GB, never saved — only the entries for listed words go into `tools/.vocab-cache/kaikki_<lang>.json`; Russian is matched with ё folded to е because Kelly writes еще) for English glosses, French genders and Russian stress marks, and has **Gemini** write the Chinese meanings (`gemini_meanings`: batches of 100 with a JSON schema, cached in `tools/.vocab-cache/gemini_<lang>.json`, so a re-run only asks for new words; it uses the assistant's key from `worker/assistant/.dev.vars` but only models the assistant doesn't — `GEMINI_MODELS` — because quotas are per model; when the free quota runs out it stops and the next run carries on). Fix a bad meaning in `ZH_FIX_FR` / `ZH_FIX_RU` / `ZH_FIX_ES` / `ZH_FIX_DE` (also used for words Gemini can't translate alone: articles, clitics) and, when Wiktionary picked a homonym, the English in `EN_FIX_FR` / `EN_FIX_RU` / `EN_FIX_ES` / `EN_FIX_DE`; for Spanish (and German) `learner_glosses()` drops slang senses (amigo: penis) and turns "alternative form of X" / "ellipsis of X" / "clipping of X" into X's meaning, looking X up in its own cache `kaikki_<es|de>_alt.json`; drop list noise (names, forms filed as words) in `FR_SKIP`. A re-run with everything cached makes no Gemini calls. Kept: words Wiktionary knows in that part of speech, French nouns only with a gender, each word once at its lowest level, most frequent first. French rows are `[le chat, m., zh, en]` (article added except before h, months and days; the gender is the reading), Russian `[молоко, молоко́, zh, en]` (the stressed form as reading). `isFrenchQuizLang()` / `isRussianQuizLang()` / `isSpanishQuizLang()` / `isGermanQuizLang()` cover them; `wordSetName()` names them "法文 A1"; they are the 檢定等級 tab of the 單字 page when French / Russian / Spanish / German is the learning language. Listening typing accepts a French, Spanish or German noun without its article and Russian without ё. Chinese (`zh.tsv`) is written as `traditional<TAB>pinyin<TAB>english[<TAB>simplified]` in Taiwan wording and readings: the script converts simplified with OpenCC `tw2s` (character by character, so 計程車 → 计程车, not 出租车) unless the 4th column gives it, and bopomofo from the space-separated pinyin with `pypinyin`, giving HSK-shaped rows. **Don't edit the JSON by hand** — fix `tools/build_vocab.py` and re-run it (`pip install wordfreq opencc-python-reimplemented pdfplumber pypinyin`; sources are cached in the git-ignored `tools/.vocab-cache/`; `--offline` reuses the cache; JLPT/TOPIK are re-fetched from the owner's Google Sheets, so editing those sheets means re-running the script). English Chinese meanings come from ECDICT via `zh_meaning()`, which drops computing-jargon senses and moves function-word / common-adverb senses first; `ZH_OVERRIDES` patches the few words it still gets wrong. Sources and licences: `data/vocab/README.md`; each path card credits its list (`path_source`). In `js/quiz.js`, `BUNDLED_SETS` maps set → row kind, `WORD_SET_FAMILIES` groups sets by language for the pickers, `QUIZ_LANG_ORDER` is derived from it, and `loadWordSet(id)` is the one loader (French alone is still read from its Google Sheet, `SHEETS.fr`). `selectWordSet(id)` opens a set. **The 單字 page (`#page-quiz`'s `#lang-card`, merged 2026-10-17, proposal C) shows the header's learning language (js/learnlang.js) in two tabs** — 主題 (a tile per topic with its path progress) and 檢定等級 (the graded lists of `WORD_SET_FAMILIES[code]` that aren't topics: JLPT, TOPIK, HSK, English 國中/高中/多益/托福, CEFR), drawn by `renderWords()`, tab in `wordsTab` / `localStorage.words_tab`; no language chosen yet → `learnChooseHtml()`. The separate 檢定 page (`#page-examquiz`), the `#topic-card` and the region → language pickers are gone: `switchPage('examquiz')` and the home page's exam shortcuts (`homeOpenExam`, which also sets the learning language) open the 檢定等級 tab (`openWords('levels')`), and a set's 返回 (`backToLanguage`) lands on the tab it came from. Its navigation slot is **複習** now (`data-tab="review"`, `openReview()` → the 間隔複習 page, which has a row to the mistake book): it isn't a page of its own, so `quizNavMark()` lights 單字 or 複習 depending on what the quiz page shows (`quizReviewShown()`), tapping 單字 while a review is on screen goes back to the word sets, and `.review-badge` shows the cards due (`updateReviewBadge()`, run by `updateMistakeBadge()`). `LANG_REGIONS` (js/quiz.js) now only groups the learning-language menu. `TOPIC_IDS` / `TOPIC_EMOJI` / `TOPIC_FILE_LANG` / `topicOf()` describe the topic sets (they are added to `BUNDLED_SETS` and, after the graded sets, to `WORD_SET_FAMILIES`); show a set's name with `wordSetName(id)` ("日文・吃飯" for a topic, else `t('quiz_<id>')`), never `t('quiz_' + id)` directly. `backToLanguage()` returns a topic set to its topic card. **Topic levels (item 10, 2026-10-23, owner's plan A):** above each topic's hand-written words is a ladder cut from the graded lists — `python tools/build_topic_levels.py --lang <ja|ko|zh|en|fr|ru|es|de> --model gemini-3.8-flash [--review] [--write] [--offline]` has Gemini (the paid key; owner's pick of the better model) put every graded word into one of 16 topics (`TOPICS`: the 10 old ones plus family, hobby, nature, feelings, time, society) or none, cached per `word|reading` in the git-ignored `tools/.vocab-cache/topics_<lang>.json`; `--review` writes `tools/.mockups/topic_levels/<lang>.html`, `--write` writes one set per step, `tp_<lang>_<topic>_<level>` (`tp_ja_food_n5`, merged small levels `tp_ja_greetings_n5-n4`, a level over `MAX_LEVEL` (80) split into parts `tp_ja_home_n2_2`; a level under `MIN_LEVEL` (10) joins the next), rows copied from the graded list so readings, meanings and recordings carry over, the hand-written words left out, and `js/topic-levels-data.js` (`TOPIC_LEVELS`, loaded before js/quiz.js; don't edit by hand). js/quiz.js registers those sets in `BUNDLED_SETS` and `QUIZ_LANG_ORDER` (not `WORD_SET_FAMILIES`, so the flashcard / listening pickers stay short); `topicOf()` also returns `level`, `topicSteps()` / `topicLevelName()` give a topic's ladder ("N3 ②", "國中" via `topic_lv_en_*`), and the 主題 tab draws `TOPIC_ALL` tiles → `openTopic(topic)` → `topicLadderHtml()` (nothing locked, the first unfinished step marked 下一步, owner's pick A1; the 6 new topics have no 基礎 step, B1); a topic set's 返回 lands on its ladder (`wordsTopic`). Done for all 8 languages (2026-10-23, ≈US$4.5 in all; review pages tools/.mockups/topic_levels/index.html): 912 sets. Merged names drop the shared prefix ("TOPIK 1–2", "HSK 1–4"). Wrong meanings in the owner's TOPIK sheets are fixed in build_vocab.py's `KO_FIX` (the sheet stays as it is) — re-run `--only sheets` and then this script with `--offline --write` for that language. The retired general sets (`jp`, `kr`, `en`, `zh`) remain in `LEGACY_SET_IDS` so their mistake-book entries still show. Flashcards pick language + display mode, then a deck (word set); listening picks everything on one page (see Practice tools below); flashcard known/unknown marks stay keyed by language (`lang|mode|word`). Use `isEnglishQuizLang()` (never `=== 'en'`) for English checks. Path progress lives in `path_progress_v2` (reset when the sets were re-ordered).
