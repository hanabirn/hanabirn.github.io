# Notepad

(Moved verbatim from CLAUDE.md on 2026-10-24; keep it up to date when changing these files.)

**Notepad (`js/notes.js` + `css/notes.css`, `#page-notes`, redesigned 2026-10-17 for review, owner's picks A–E)**: `renderNotes()` draws everything into `#notes-root`: a side list on screens ≥1024px (filters 全部 / 要複習 / 回顧筆記 / 圖庫, folders, tags, trash; the page is 1180px wide there) or a chip row on phones (＋ bottom-right, `.notes-fab`), a search, and cards (title or first line, two-line preview, tags, source, review state). A card opens the reader (`notesReaderHtml`), then the editor (`notesEditorHtml`: title, folder, learning language, tags with suggestions, B / H / list / highlight / word-card tools on a textarea, autosave `NOTES_SAVE_MS`; 上一步 / 下一步 and Ctrl+Z / Ctrl+Y run the editor's own history `notesHist` — a burst of typing is one step, a big deletion or a formatting button its own — because the browser's undo misses `setRangeText` and phones have no Ctrl+Z; `renderNotes()` saves the editor before redrawing). The text is light markup (`notesRender`): `# ` heading, `- ` list, `**bold**`, `==highlight==`, and a line `word — meaning` (— – or =) is a word card (`notesPairs`). Notes `{id, title, text, category, tags, lang, pinned, star, rv, noCards, src, createdAt, updatedAt, deletedAt, purged}` in `notepad_notes`, folders `{id, name, color, parentId, updatedAt, deleted}` in `notepad_categories`, both in `SYNC_KEYS` (`notesSyncMerge`: per id, the newer `updatedAt` wins; deleting keeps a tombstone so it syncs); attachments stay in IndexedDB (`hanabi_notes_db`, this device; the ⋯ menu's backup file carries them). The 圖庫 view has its own 上傳圖片 (`notesGalleryUpload`): images belong to a note, so a batch becomes a new note 「照片 10/22」. Deleting moves a note to the trash for `NOTES_TRASH_DAYS` (30), then it becomes a tombstone; deleting a folder keeps its notes (they go to 未分類). **＋筆記** (`notesAddFrom({kind, ref, label, title, text, lang})`): grammar points and examples (`grammarNote`), reading passages and glossary words (`readingNote`), the listening transcript (`listeningNote`), the dictionary (`dictNote`), the mistake book (`mbNote`) and the lesson preview (`lessonNote`, both via `notesAddWord`, one note per word set) — one note per source, later saves add their new lines, starred, in the folder used last (`notes_last_folder`), a toast with 打開, and `src` gives the reader a 回到… link (`notesOpenSource`, switching the learning language when needed). **Review**: word-card lines become `srs_quiz` cards (`notesSyncCards` / `notesTidyCards`, set id `note_<lang>` — `wordSetName` says "筆記・日文", the is*QuizLang checks accept it — id `note|<note>|<word>`; 不要加入 sets `noCards`; 現在練一次 runs `startSrsQuizReview('notes', cards)`, whose 返回 comes back here); ⭐ notes have `rv` and come back after `NOTES_REVIEW_DAYS` 1 / 3 / 7 / 14 / 30 days (記得了 moves up, 還不熟 → tomorrow), shown as a banner and the 回顧筆記 view (`notesStartReview`), and as a step on the home 今天 card (`notesDueCount`). `notesTidyCards()` runs on load and after an account sync, because `srs_quiz` merges as a union. Escape with `notesEsc()` (quotes too). The quiz results table has one too (`resultNote`).
