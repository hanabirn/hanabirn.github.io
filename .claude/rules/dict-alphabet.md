# Dictionary and alphabet chart

(Moved verbatim from CLAUDE.md on 2026-10-24; keep it up to date when changing these files.)

**Dictionary (`js/dict.js` + `css/dict.css`, `#page-dict`)**: since 2026-10-22 (owner's picks A1+B+C1+D+E) the word's language is a pill + region menu in front of the box (`renderDictLangs`, `#dict-pick`), and one call to the 小花火 Worker's `/dict` (`worker/assistant/src/dict.js`, `dictAsk`) gives the word in every other site language (`tr`, a flag and 🔊 each), its Wiktionary senses translated into the interface language with the English kept for 看英文原文 (`dictToggleEn`), a reading, and for an idiom / proverb a 白話說明 (`note`); without a Wiktionary entry Gemini writes the senses (`src: 'gemini'`). The Worker tries the free key's lite models first (`FREE_MODELS`, not the ones the chat uses), then the paid `GEMINI_PAID_KEY` (prepaid hanabi-tts) capped at `DICT_PAID_PER_DAY` per isolate, rate-limits per IP (`DICT_LIMITER`), and keeps every answer in KV `DICT` (shared; ~1,000 new words a day fit the free plan — the Cache API doesn't work on workers.dev); the page keeps its own `dict_cache`. Wikimedia refuses a Worker request without a User-Agent. If the Worker can't answer, the page falls back to what it did before: three CORS-enabled services called from the browser, each rendering its own section so one failing never blanks the others; a new search aborts the previous one (`AbortController`). Wiktionary REST `page/definition/{word}` gives part of speech + **English** definitions grouped by language code (try the word as typed, then lower-case, then Capitalised — titles are case-sensitive); its HTML is reduced to text via `DOMParser` after dropping `<style>` blocks. Tatoeba `/unstable/sentences` (requires `sort`) gives example sentences with a translation into the site language. Its Chinese is mixed and mostly Simplified with mainland wording, so with a Chinese interface (since the big check of 2026-10-24) a translation already in the interface's script is preferred (`tatoebaTranslation`), and every Chinese example line (`data-zh`: the sentence when the word is Chinese, the translation when the target is) that still has characters of the other script (`DICT_SIMP_ONLY` / `DICT_TRAD_ONLY`, `dictZhWrong`) goes to the Worker's `POST /dict/zh {to, lines}` (`dictZhFix`), which rewrites them with the same free-first Gemini models in Taiwan Traditional or Mainland Simplified wording and keeps the answer in KV `DICT` (one key per batch); the page shows Tatoeba's lines first and swaps them in (the sentence's mark and 🔊 text too). `DICT_LIMITER` is 20 a minute. Measured then: a new word takes ~2–3 s from the Worker and Tatoeba ~1–2 s in parallel, a stored one ~0.2 s. MyMemory is a translation memory that mistranslates lone words (食べる → 美食), so the headline translation is the first Wiktionary gloss translated from English (to eat → 吃); only words Wiktionary lacks (many Chinese ones) are sent to MyMemory directly. MyMemory allows ~5,000 chars/day per visitor IP. Attribution for all three is in the page footer (`dict_sources`). Phones reach the page from the "More" sheet. `escHtml()` also escapes `"` because dictionary output goes into `data-*` attributes.

**Alphabet chart (`js/alphabet.js` + `js/alphabet-data.js` + `css/alphabet.css`, `#page-alphabet`)**: a beginner letter chart with tabs for English, hiragana, katakana (both with dakuon / handakuon), Korean (basic + double consonants, basic + compound vowels), 注音 (with pinyin), Russian, French, German (+ Ä Ö Ü ß) and Spanish (+ Ñ). Every entry in `ALPHABETS` is `[glyph, reading, text to speak, example word, word reading, emoji, meaning zh, meaning zh-Hans, meaning en]`, hand-written — edit the data file directly. The text to speak is not always the glyph: Korean consonants say their name and then their sound with ㅏ ("기역, 가"), vowels the vowel syllable (아), 注音 symbols a character with that sound (ㄅ → 玻), Russian/Spanish letters their names, because TTS reads lone symbols unreliably; English/French/German letters are spoken in lower case (French Y as "i grec"), because phone voices read a lone capital as "capital A" / "A majuscule". An empty example word marks a letter that is basically unused (ヂ, ヅ, ヲ). Meanings are only stored in zh / zh-Hans / en (other UI languages get English) and are hidden when the UI language is the tab's own language. `alphaHighlight()` marks the letter inside the example word. Sound goes through `speakText()` (see Speech below). Reached from the desktop nav, the phone "More" sheet and the home page's "剛開始學？" button; the chosen tab is kept in `localStorage['alpha_tab']`. **Small tabs (big check 2026-10-24, owner's pick):** each chart is cut into pages of at most `ALPHA_PAGE_ROWS` (3) rows — a row is one 行 of the 五十音 (`ALPHA_ROW_HEADS`, kana sections in `ALPHA_GOJUON_SECS`) or `ALPHA_ROW` (5) letters elsewhere; whole sections share a page when they fit, a longer one is cut by rows (`alphaPages()`), and the chips under the tabs (`#alpha-pages`, `setAlphaPage`, not stored) are named by `alphaPageName()` (清音 あ–そ, A–O, 雙子音・基本母音). A section title only shows when two share a page. On computers every grid is 5 a row and the cards are a little flatter (the word's reading and meaning share a line), so every page of every tab measured ≤ 938px in a 1920×940 frame.
