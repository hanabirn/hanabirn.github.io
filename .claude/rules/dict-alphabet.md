# Dictionary and alphabet chart

(Moved verbatim from CLAUDE.md on 2026-10-24; keep it up to date when changing these files.)

**Dictionary (`js/dict.js` + `css/dict.css`, `#page-dict`)**: since 2026-10-22 (owner's picks A1+B+C1+D+E) the word's language is a pill + region menu in front of the box (`renderDictLangs`, `#dict-pick`), and one call to the 小花火 Worker's `/dict` (`worker/assistant/src/dict.js`, `dictAsk`) gives the word in every other site language (`tr`, a flag and 🔊 each), its Wiktionary senses translated into the interface language with the English kept for 看英文原文 (`dictToggleEn`), a reading, and for an idiom / proverb a 白話說明 (`note`); without a Wiktionary entry Gemini writes the senses (`src: 'gemini'`). The Worker tries the free key's lite models first (`FREE_MODELS`, not the ones the chat uses), then the paid `GEMINI_PAID_KEY` (prepaid hanabi-tts) capped at `DICT_PAID_PER_DAY` per isolate, rate-limits per IP (`DICT_LIMITER`), and keeps every answer in KV `DICT` (shared; ~1,000 new words a day fit the free plan — the Cache API doesn't work on workers.dev); the page keeps its own `dict_cache`. Wikimedia refuses a Worker request without a User-Agent. If the Worker can't answer, the page falls back to what it did before: three CORS-enabled services called from the browser, each rendering its own section so one failing never blanks the others; a new search aborts the previous one (`AbortController`). Wiktionary REST `page/definition/{word}` gives part of speech + **English** definitions grouped by language code (try the word as typed, then lower-case, then Capitalised — titles are case-sensitive); its HTML is reduced to text via `DOMParser` after dropping `<style>` blocks. Tatoeba `/unstable/sentences` (requires `sort`) gives example sentences with a translation into the site language. MyMemory is a translation memory that mistranslates lone words (食べる → 美食), so the headline translation is the first Wiktionary gloss translated from English (to eat → 吃); only words Wiktionary lacks (many Chinese ones) are sent to MyMemory directly. MyMemory allows ~5,000 chars/day per visitor IP. Attribution for all three is in the page footer (`dict_sources`). Phones reach the page from the "More" sheet. `escHtml()` also escapes `"` because dictionary output goes into `data-*` attributes.

**Alphabet chart (`js/alphabet.js` + `js/alphabet-data.js` + `css/alphabet.css`, `#page-alphabet`)**: a beginner letter chart with tabs for English, hiragana, katakana (both with dakuon / handakuon), Korean (basic + double consonants, basic + compound vowels), 注音 (with pinyin), Russian, French, German (+ Ä Ö Ü ß) and Spanish (+ Ñ). Every entry in `ALPHABETS` is `[glyph, reading, text to speak, example word, word reading, emoji, meaning zh, meaning zh-Hans, meaning en]`, hand-written — edit the data file directly. The text to speak is not always the glyph: Korean consonants say their name and then their sound with ㅏ ("기역, 가"), vowels the vowel syllable (아), 注音 symbols a character with that sound (ㄅ → 玻), Russian/Spanish letters their names, because TTS reads lone symbols unreliably; English/French/German letters are spoken in lower case (French Y as "i grec"), because phone voices read a lone capital as "capital A" / "A majuscule". An empty example word marks a letter that is basically unused (ヂ, ヅ, ヲ). Meanings are only stored in zh / zh-Hans / en (other UI languages get English) and are hidden when the UI language is the tab's own language. `alphaHighlight()` marks the letter inside the example word. Sound goes through `speakText()` (see Speech below). Reached from the desktop nav, the phone "More" sheet and the home page's "剛開始學？" button; the chosen tab is kept in `localStorage['alpha_tab']`.
