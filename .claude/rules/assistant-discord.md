# 小花火 AI assistant and the Discord bot

(Moved verbatim from CLAUDE.md on 2026-10-24; keep it up to date when changing these files.)

**AI assistant (`js/assistant.js` + `css/assistant.css`, Worker in `worker/assistant/`)**: a floating 小花火 (desktop: 96px in the bottom-right corner until dragged — since 2026-10-22 she can be dragged anywhere, the place kept per device in `assistant_fab_pos` as shares of the window, a press without moving still opens the chat, which opens beside her (`fabPlacePanel`); phones: bottom-left above the tab bar, whole — it was half off the edge until 2026-10-17 — and sliding away while scrolling down) opens a chat panel. The static site can't hold a key, so messages go to the Cloudflare Worker `hanabi-assistant` (`ASSISTANT_API`; `localhost:8787` when the site runs on localhost), which keeps `GEMINI_API_KEY` as a secret, builds 小花火's persona + the site's feature list in `persona()`, and calls Gemini, trying the models in `MODELS` (wrangler.jsonc) in order, **fastest first** (measured 2026-10-04, time to the first words: gemini-3.6-flash ~0.7 s, 3.5-flash-lite ~0.6 s, 3.8-flash ~5 s, 3.5-flash ~7 s, 3.7-flash often a 503 after 7 s; re-measure if replies get slow). Each flash model's free tier is only **~20 requests a day**; any failure (429 quota, 503, 500, or no answer within `FIRST_BYTE_MS` 5 s) moves on to the next, and a spent (429 per-day) or slow model is skipped for an hour / 10 minutes (`spent`, in isolate memory). The site asks with `stream: true`: the Worker uses `streamGenerateContent?alt=sse`, waits for the first words (an empty stream moves on), then streams plain text that `assistantAsk()` shows as it arrives while 小花火's mouth moves; without `stream` it still answers `{ reply }` JSON (gemini-2.5-* is closed to new keys). Guards: `ALLOWED_ORIGINS`, a rate-limit binding (8/min per IP), 12 turns × 600 chars. The key's Google project (`hanabi-assistant-510517`) has **billing disabled on purpose** so only the free tier is used — with billing linked, Gemini answers 402 "prepayment credits depleted". Local test: key in the git-ignored `worker/assistant/.dev.vars`, then `wrangler dev --port 8787` from that folder (wrangler is installed in the osu project). The chat is kept in sessionStorage; our own error notices are flagged `err` and never sent. When site features change, update the feature list in `persona()`.

**Discord bot (`worker/discord/`, Cloudflare Worker `hanabi-discord`, added 2026-10-09)**: a separate bot from the owner's Render bots — `/quiz` (單字測驗; the result lists every word, right or wrong, 10 a page), `/grammar study` (文法 in order, every question of a point — 3, or 6 for Japanese with the 進階 ones; a 句子排序 question is asked as “which part goes on ★” — the place kept in KV `PREFS` as `g:<user>:<lang>`) and `/grammar quiz` (random questions from a level, the missed ones explained; both since 2026-10-15), `/dictionary` (字典), `/ask` (問小花火, 2026-10-15: general questions, multi-turn via a 繼續問 modal; only free AI — its own no-billing Gemini key `GEMINI_API_KEY` rotating `ASK_MODELS`, then Workers AI, 20 a person a day — see worker/discord/README.md) answered through Discord's HTTP interactions (Ed25519-signed POSTs; replies are deferred and written through the interaction webhook). It reads the live site's `data/vocab/*.json` and `data/grammar/*.json` from `SITE`, so it only sees what has been pushed. Stateless: a quiz lives in its buttons' `custom_id`s and is rebuilt from a seed. Replies come in the site's 9 languages (`/language`, saved in KV `PREFS`, else the Discord locale); meanings and grammar explanations only exist in Chinese / English, so the other languages get English (Simplified is converted). `src/sets.js` mirrors `WORD_SET_FAMILIES` — add new word sets there too. Since 2026-10-17 (owner's picks from a mockup): question cards are ink grey and answers green / red, a 🟩🟥⬜ progress bar, `/quiz` remembers the last set (language optional; a drop-down on question 1 switches), results offer a round of the missed ones, `/grammar study` shows the explanation first (開始練習), long options become A–D, `/help` is grouped, and `/dictionary` attaches the site's recording (multipart edit in `src/index.js`). Setup, registration (`node register.mjs`, token in the git-ignored `.dev.vars`) and the local end-to-end test (`node test.mjs <wrangler>`) are in its README.
