形容詞 ＋ 一點 ／ 有一點 ＋ 形容詞

一點・有一點

一點 vs 有一點 — Chinese grammar, HSK 1–2

接續

形容詞 ＋ 一點（比較、希望更～）　有一點 ＋ 形容詞（有點～，通常是不好的感覺）
adjective + 一點 (comparing / asking for “a bit more”)　有一點 + adjective (a bit … — usually negative)

說明

「一點」放在形容詞後面，用來比較或要求：便宜一點（便宜一點吧）、請說慢一點。「有一點」放在形容詞前面，表示「有點～」而且多半不滿意：這件衣服有一點貴。

一點 after an adjective compares or asks: 便宜一點 (a bit cheaper), 請說慢一點 (please speak a bit slower). 有一點 before an adjective means “a bit …”, usually negative: 這件衣服有一點貴 (these clothes are a bit pricey).

注意事項

  • 大陸常說「一點兒」「有點兒」；台灣常說「一點」「有點」。
    Mainland speakers add 兒 (一點兒, 有點兒); Taiwan usually doesn't.

常見錯誤

  • ✗ 這件衣服一點貴。
    ✓ 這件衣服有一點貴。
    說「有點～」要用「有一點」放在形容詞前面。
    “A bit …” is 有一點 before the adjective.
  • ✗ 可以有一點便宜嗎？
    ✓ 可以便宜一點嗎？
    要求「再～一點」用「形容詞＋一點」。
    Asking for “a bit more …” is adjective + 一點.

例句

可以便宜一點嗎？
Kěyǐ piányí yìdiǎn ma?
Could you make it a bit cheaper?
請說慢一點。
Qǐng shuō màn yìdiǎn.
Please speak a bit slower.
今天有一點冷。
Jīntiān yǒu yìdiǎn lěng.
It's a bit cold today.
