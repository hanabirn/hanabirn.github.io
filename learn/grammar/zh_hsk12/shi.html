A 是 B

A 是 B

A is B (是) — Chinese grammar, HSK 1–2

接續

名詞 ＋ 是 ＋ 名詞
noun + 是 + noun

說明

「是」連接兩個名詞：我是學生、他是老師。否定是「不是」：我不是日本人。

是 links two nouns: 我是學生 (I'm a student), 他是老師 (he's a teacher). The negative is 不是: 我不是日本人.

注意事項

  • 形容詞前面不用「是」：說「我很忙」，不說「我是忙」。
    No 是 before adjectives: 我很忙, not 我是忙.

常見錯誤

  • ✗ 我是很忙。
    ✓ 我很忙。
    形容詞前面不加「是」，通常加「很」。
    No 是 before an adjective — use 很.
  • ✗ 我沒是學生。
    ✓ 我不是學生。
    「是」的否定一定用「不」。
    是 is always negated with 不.

例句

我是學生。
Wǒ shì xuéshēng.
I'm a student.
他是我的老師。
Tā shì wǒ de lǎoshī.
He's my teacher.
我不是日本人，我是台灣人。
Wǒ bú shì Rìběnrén, wǒ shì Táiwānrén.
I'm not Japanese, I'm Taiwanese.
