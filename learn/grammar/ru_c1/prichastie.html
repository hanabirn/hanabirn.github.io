文法 › 俄文 C1

читающий・прочитанный

形動詞

Participles (причастия) — Russian grammar, C1

接續

主動現在：-ущий／-ющий／-ащий／-ящий（читающий）；主動過去：-вший（прочитавший）；被動過去：-нный／-тый（прочитанный, открытый）
Active present: -ущий / -ющий / -ащий / -ящий (читающий); active past: -вший (прочитавший); passive past: -нный / -тый (прочитанный, открытый)

說明

形動詞像形容詞一樣修飾名詞並變格，可以代替 который 子句：студент, который читает → читающий студент；книга, которую прочитали → прочитанная книга。書面語常用。

Participles modify nouns like adjectives and decline; they replace a который clause: студент, который читает → читающий студент; книга, которую прочитали → прочитанная книга. Common in writing.

注意事項

  • 形動詞短語可以放在名詞後面，用逗號隔開：Девушка, стоящая у окна, — моя сестра.
    A participle phrase can follow the noun, set off by commas: Девушка, стоящая у окна, — моя сестра.

常見錯誤

  • ✗ Я видел вчера человека, читающего газету.
    ✓ Я видел вчера человека, читавшего газету.
    過去的動作用過去主動形動詞 читавший。
    A past action takes the past active participle читавший.
  • ✗ Письмо, написанное мной вчера, лежат на столе.
    ✓ Письмо, написанное мной вчера, лежит на столе.
    動詞和主詞 письмо（單數）一致。
    The verb agrees with письмо (singular).
