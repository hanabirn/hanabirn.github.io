文法 › 德文 C1

je … desto／umso

越……越……

The more… the more… (je … desto) — German grammar, C1

接續

Je ＋ 比較級 ＋ …動詞（句末）, desto／umso ＋ 比較級 ＋ 動詞 ＋ 主詞 …
Je + comparative … verb (last), desto / umso + comparative + verb + subject …

說明

je 子句是從句，動詞放句末；desto／umso 子句的動詞緊接在比較級後面：Je länger ich warte, desto nervöser werde ich.（等得越久，我越緊張。）

The je clause is subordinate (verb last); in the desto / umso clause the verb follows the comparative directly: Je länger ich warte, desto nervöser werde ich.

注意事項

  • je nachdem（視……而定）：Je nachdem, wie das Wetter ist, fahren wir.
    je nachdem (depending on): Je nachdem, wie das Wetter ist, fahren wir.

常見錯誤

  • ✗ Je mehr du übst, desto du wirst besser.
    ✓ Je mehr du übst, desto besser wirst du.
    desto ＋ 比較級後面是動詞，再接主詞。
    desto + comparative, then the verb, then the subject.
  • ✗ Je ich älter werde, desto…
    ✓ Je älter ich werde, desto…
    je 後面先接比較級。
    je is followed by the comparative.

例句

Je früher wir losfahren, desto weniger Verkehr gibt es.
越早出發，車就越少。
The earlier we leave, the less traffic there is.
Je mehr ich über das Thema lese, umso interessanter finde ich es.
我對這個主題讀得越多，就越覺得有趣。
The more I read about the topic, the more interesting I find it.
Je teurer das Hotel ist, desto besser sollte der Service sein.
旅館越貴，服務就應該越好。
The more expensive the hotel, the better the service should be.
