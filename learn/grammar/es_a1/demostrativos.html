文法 › 西班牙文 A1

este・ese・aquel

指示詞：這、那

Demonstratives: este, ese, aquel — Spanish grammar, A1

接續

este／esta／estos／estas 這・ese／esa／esos／esas 那（較近）・aquel／aquella／aquellos／aquellas 那（遠）
este / esta / estos / estas this · ese / esa / esos / esas that · aquel / aquella / aquellos / aquellas that (far)

說明

西班牙文分三種距離：este 在我旁邊，ese 在你旁邊或不遠，aquel 離我們都很遠。要跟名詞的性別、單複數一致：esta camisa、esos zapatos。

Spanish has three distances: este is near me, ese near you or not far, aquel far from us both. They agree with the noun: esta camisa, esos zapatos.

注意事項

  • 指一件事或不知道是什麼東西時用 esto、eso：¿Qué es esto?
    For an idea or an unknown thing use esto, eso: ¿Qué es esto?

常見錯誤

  • ✗ este casa
    ✓ esta casa
    casa 是陰性，用 esta。
    casa is feminine: esta.
  • ✗ estes libros
    ✓ estos libros
    este 的複數是 estos。
    The plural of este is estos.

例句

Este café está muy rico.
這杯咖啡很好喝。
This coffee is delicious.
¿Cuánto cuestan esas gafas?
那副眼鏡多少錢？
How much are those glasses?
Aquella montaña es muy alta.
那座山很高。
That mountain over there is very high.
