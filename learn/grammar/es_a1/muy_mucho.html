文法 › 西班牙文 A1

muy ／ mucho

muy 和 mucho：很、很多

muy or mucho? — Spanish grammar, A1

接續

muy ＋ 形容詞／副詞・動詞 ＋ mucho・mucho/a/os/as ＋ 名詞
muy + adjective / adverb · verb + mucho · mucho/a/os/as + noun

說明

「muy」放在形容詞、副詞前面（muy grande、muy bien）；「mucho」放在動詞後面（Trabajo mucho），或放在名詞前面當「很多」，這時要跟名詞一致（muchas personas）。

muy goes before adjectives and adverbs (muy grande, muy bien); mucho goes after a verb (Trabajo mucho) or before a noun as “a lot of”, agreeing with it (muchas personas).

注意事項

  • 「Muchas gracias」（非常感謝）就是 mucho ＋ 名詞。
    Muchas gracias (thanks a lot) is mucho + noun.

常見錯誤

  • ✗ Es mucho bonito.
    ✓ Es muy bonito.
    形容詞前面用 muy。
    Before an adjective use muy.
  • ✗ Tengo mucho amigas.
    ✓ Tengo muchas amigas.
    mucho 放在名詞前時要跟名詞一致。
    Before a noun mucho agrees with it.

例句

Hoy hace mucho calor.
今天很熱。
It's very hot today.
Mi profesora habla muy rápido.
我的老師說話很快。
My teacher speaks very fast.
Me gusta mucho este barrio.
我很喜歡這一區。
I really like this neighbourhood.
