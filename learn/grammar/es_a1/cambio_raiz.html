文法 › 西班牙文 A1

e → ie・o → ue

會變音的動詞：e → ie、o → ue

Stem-changing verbs: e → ie, o → ue — Spanish grammar, A1

接續

querer → quiero・quieres・quiere・queremos・queréis・quieren　poder → puedo・puedes・puede・podemos・podéis・pueden
querer → quiero · quieres · quiere · queremos · queréis · quieren · poder → puedo · puedes · puede · podemos · podéis · pueden

說明

有些動詞的字根母音會變：e 變 ie（querer → quiero）、o 變 ue（dormir → duermo）。只有 nosotros 和 vosotros 不變：queremos、dormimos。

Some verbs change the vowel in the stem: e → ie (querer → quiero), o → ue (dormir → duermo). nosotros and vosotros keep it: queremos, dormimos.

注意事項

  • 常見的 e → ie：empezar、pensar、preferir、cerrar；o → ue：poder、volver、dormir、costar。
    Common e → ie: empezar, pensar, preferir, cerrar; o → ue: poder, volver, dormir, costar.
  • jugar 是 u → ue：juego、juegas。
    jugar goes u → ue: juego, juegas.

常見錯誤

  • ✗ Yo quero un café.
    ✓ Yo quiero un café.
    querer 的 yo 是 quiero。
    querer with yo is quiero.
  • ✗ Nosotros puedemos ir.
    ✓ Nosotros podemos ir.
    nosotros 不變音。
    nosotros keeps the o.
