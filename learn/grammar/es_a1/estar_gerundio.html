estar ＋ -ando／-iendo

estar ＋ 現在分詞：正在…

estar + gerund — be doing — Spanish grammar, A1

接續

estar ＋ 現在分詞：-ar → -ando（hablando）・-er／-ir → -iendo（comiendo、viviendo）
estar + gerund: -ar → -ando (hablando) · -er / -ir → -iendo (comiendo, viviendo)

說明

說「現在正在做」的事，用 estar＋現在分詞：Estoy comiendo.（我正在吃飯。）¿Qué estás haciendo?（你在做什麼？）

For what is going on right now: estar + gerund: Estoy comiendo (I'm eating), ¿Qué estás haciendo? (What are you doing?).

注意事項

  • 幾個不規則的：leer → leyendo、dormir → durmiendo。
    Some irregular ones: leer → leyendo, dormir → durmiendo.

常見錯誤

  • ✗ Estoy comer.
    ✓ Estoy comiendo.
    estar 後面用現在分詞。
    After estar use the gerund.
  • ✗ Soy trabajando.
    ✓ Estoy trabajando.
    「正在」用 estar，不用 ser。
    “Be doing” takes estar, not ser.

例句

Estoy estudiando para el examen.
我正在準備考試。
I'm studying for the exam.
¿Qué estás leyendo?
你在看什麼書？
What are you reading?
Está lloviendo mucho.
雨下得很大。
It's raining hard.
