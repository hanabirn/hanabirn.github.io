ein neuer Film

形容詞字尾（不定冠詞後）

Adjective endings after ein, kein, mein — German grammar, A2

接續

主格：ein neuer（陽）・eine neue（陰）・ein neues（中）　第四格：einen neuen・eine neue・ein neues　第三格：一律 -en
nominative: ein neuer · eine neue · ein neues · accusative: einen neuen · eine neue · ein neues · dative: always -en

說明

ein 本身看不出性別時（ein Mann、ein Kind），形容詞要「補上」性別的字尾：ein großer Hund（陽）、ein kleines Haus（中）。kein、mein 等所有格也一樣：mein neuer Job。

When ein doesn't show the gender (ein Mann, ein Kind), the adjective shows it: ein großer Hund, ein kleines Haus. kein and mein etc. work the same: mein neuer Job.

注意事項

  • 可以記：der → -er、das → -es，形容詞「借走」冠詞的字尾。
    Think of the adjective borrowing the article's ending: der → -er, das → -es.

常見錯誤

  • ✗ Das ist ein schöne Tag.
    ✓ Das ist ein schöner Tag.
    Tag 是陽性，ein 後面形容詞加 -er。
    Tag is masculine: ein + -er.
  • ✗ Sie hat ein kleine Kind.
    ✓ Sie hat ein kleines Kind.
    Kind 是中性，加 -es。
    Kind is neuter: -es.
