文法 › 德文 A2

würde・hätte gern・könnten Sie

第二虛擬式：禮貌的請求

Konjunktiv II: polite requests — German grammar, A2

接續

hätte gern（想要）・würde gern ＋ 原形（想做）・Könnten Sie …?・Würden Sie …?・wäre
hätte gern (would like) · würde gern + infinitive (would like to) · Könnten Sie …? · Würden Sie …? · wäre

說明

第二虛擬式讓請求聽起來更客氣：Ich hätte gern ein Stück Kuchen.（我想要一塊蛋糕。）Könnten Sie mir helfen?（您可以幫我嗎？）Ich würde gern nach Island reisen.（我很想去冰島旅行。）

Konjunktiv II makes requests politer: Ich hätte gern ein Stück Kuchen, Könnten Sie mir helfen?, Ich würde gern nach Island reisen.

注意事項

  • würde ＋ 原形可以表達很多「會、想要」：Ich würde lieber zu Hause bleiben.
    würde + infinitive covers many “would” sentences: Ich würde lieber zu Hause bleiben.

常見錯誤

  • ✗ Ich hatte gern einen Kaffee.
    ✓ Ich hätte gern einen Kaffee.
    客氣的「想要」是 hätte（有變音）。
    Polite “would like” is hätte, with the umlaut.
  • ✗ Würden Sie mir helfen können bitte?
    ✓ Könnten Sie mir bitte helfen?
    用 Könnten Sie … 就夠了。
    Könnten Sie … is enough.

例句

Könnten Sie das bitte wiederholen?
可以請您再說一次嗎？
Could you repeat that, please?
Ich hätte gern zwei Tickets für morgen.
我想要兩張明天的票。
I'd like two tickets for tomorrow.
Am liebsten würde ich jetzt schlafen.
我現在最想做的就是睡覺。
What I'd most like to do now is sleep.
