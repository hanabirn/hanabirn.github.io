文法 › 德文 B2

sodass・indem・dadurch, dass

結果與方式：sodass、indem

Result and means: sodass, indem — German grammar, B2

接續

sodass／so …, dass（以致於）・indem（藉由…）・dadurch, dass（透過…）＋ 副句（動詞在最後）
sodass / so …, dass (so that, with the result) · indem (by doing) · dadurch, dass (by the fact that) + clause (verb last)

說明

Es regnete stark, sodass das Spiel abgesagt wurde.（雨下得很大，以致比賽取消了。）Man lernt eine Sprache, indem man sie spricht.（藉由說來學一種語言。）

Es regnete stark, sodass das Spiel abgesagt wurde. Man lernt eine Sprache, indem man sie spricht.

注意事項

  • indem 回答 wie?（怎麼做到的），不是 wann?（什麼時候）。
    indem answers “how?”, not “when?”.

常見錯誤

  • ✗ Er war so müde, sodass er sofort einschlief.
    ✓ Er war so müde, dass er sofort einschlief.
    前面有 so ＋ 形容詞，後面只用 dass。
    With so + adjective, use just dass.
  • ✗ Sie hat abgenommen, indem sie hat mehr Sport gemacht.
    ✓ Sie hat abgenommen, indem sie mehr Sport gemacht hat.
    indem 子句的動詞放最後。
    The indem clause has the verb last.

例句

Der Bus hatte Verspätung, sodass ich den Zug verpasste.
公車誤點，結果我錯過了火車。
The bus was late, so I missed the train.
Du kannst Strom sparen, indem du das Licht ausmachst.
你可以藉由關燈來省電。
You can save electricity by turning off the light.
Er wurde gesund, dadurch dass er viel schlief.
他靠著多睡覺恢復了健康。
He got better by sleeping a lot.
