eine Entscheidung treffen・in Frage kommen

名詞＋動詞的固定搭配

Noun–verb phrases — German grammar, B2

接續

eine Entscheidung treffen（做決定）・eine Frage stellen（提問）・Kritik üben（批評）・in Frage kommen（可以考慮）・zur Verfügung stehen（可供使用）・Bescheid sagen（通知）
eine Entscheidung treffen · eine Frage stellen · Kritik üben · in Frage kommen · zur Verfügung stehen · Bescheid sagen

說明

書面語常用名詞加固定動詞代替一個動詞：entscheiden → eine Entscheidung treffen。動詞是固定的，不能換：不說 eine Entscheidung machen。

Formal German often uses a noun + a fixed verb instead of a single verb: entscheiden → eine Entscheidung treffen. The verb is fixed — not eine Entscheidung machen.

注意事項

  • 背的時候要連動詞和介系詞一起背。
    Learn them with their verb and preposition.

常見錯誤

  • ✗ Wir müssen bald eine Entscheidung machen.
    ✓ Wir müssen bald eine Entscheidung treffen.
    「做決定」是 eine Entscheidung treffen。
    “Make a decision” is eine Entscheidung treffen.
  • ✗ Darf ich eine Frage fragen?
    ✓ Darf ich eine Frage stellen?
    「提問」是 eine Frage stellen。
    “Ask a question” is eine Frage stellen.

例句

Der Raum steht allen Studierenden zur Verfügung.
這個空間開放給所有學生使用。
The room is available to all students.
Sag mir bitte Bescheid, wenn du ankommst.
你到了請跟我說一聲。
Please let me know when you arrive.
Dieser Termin kommt für mich nicht in Frage.
這個時間我不考慮。
This date is out of the question for me.
