文法 › 西班牙文 A2

hace … que・desde hace

時間的長度：hace、desde hace、llevar

How long: hace, desde hace, llevar — Spanish grammar, A2

接續

hace ＋ 時間（…之前）・hace ＋ 時間 ＋ que ＋ 現在式（…已經…了）・現在式 ＋ desde hace ＋ 時間・llevar ＋ 時間 ＋ 現在分詞
hace + time (ago) · hace + time + que + present (for …) · present + desde hace + time · llevar + time + gerund

說明

「…之前」用 hace：Llegué hace dos horas.（我兩小時前到的。）從過去持續到現在的事，西班牙文用現在式：Vivo aquí desde hace tres años. ＝ Hace tres años que vivo aquí.（我住在這裡三年了。）

“Ago” is hace: Llegué hace dos horas. For something still going on, Spanish uses the present: Vivo aquí desde hace tres años = Hace tres años que vivo aquí.

注意事項

  • llevar 也很常用：Llevo dos años estudiando español.（我學西班牙文兩年了。）
    llevar is common too: Llevo dos años estudiando español.

常見錯誤

  • ✗ Estudio español por dos años.
    ✓ Estudio español desde hace dos años.
    持續到現在的時間用 desde hace。
    Ongoing duration takes desde hace.
  • ✗ Lo vi antes de tres días.
    ✓ Lo vi hace tres días.
    「…之前」用 hace。
    “Ago” is hace.

例句

Nos conocimos hace diez años.
我們十年前認識的。
We met ten years ago.
Hace mucho tiempo que no te veo.
好久不見。
I haven't seen you for ages.
Llevo una hora esperando el autobús.
我等公車等了一個小時。
I've been waiting for the bus for an hour.
