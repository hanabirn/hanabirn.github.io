V/A-았/었더라면

如果當時～的話（後悔、慶幸）

if … had … — Korean grammar, Level 5

接續

母音ㅏ・ㅗ → -았더라면　其他 → -었더라면　하다 → 했더라면　名詞 → 였더라면／이었더라면
ㅏ/ㅗ → -았더라면　others → -었더라면　하다 → 했더라면　nouns → 였더라면 / 이었더라면

說明

假設過去沒有發生的事，常表示後悔或慶幸：조금만 일찍 출발했더라면 늦지 않았을 거예요（要是早一點出發就不會遲到了）、네가 없었더라면 큰일 날 뻔했어（要是沒有你就糟了）。

Imagines a past that did not happen, often with regret or relief: 조금만 일찍 출발했더라면 늦지 않았을 거예요 (if we had left a little earlier, we wouldn't have been late), 네가 없었더라면 큰일 날 뻔했어 (without you, it would have been a disaster).

注意事項

  • 後句常用「-았/었을 거예요、-았/었을 텐데、-(으)ㄹ 뻔했다」。
    Followed by -았/었을 거예요, -았/었을 텐데 or -(으)ㄹ 뻔했다.
  • 意思接近「-았/었으면」，「-았/었더라면」更強調假設。
    Close to -았/었으면, with more stress on the "if only".

常見錯誤

  • ✗ 일찍 출발하더라면 늦지 않았을 거예요.
    ✓ 일찍 출발했더라면 늦지 않았을 거예요.
    過去的假設要用「-았/었더라면」。
    A past supposition takes -았/었더라면.
  • ✗ 조금만 더 공부했더라면 합격할 거예요.
    ✓ 조금만 더 공부했더라면 합격했을 거예요.
    後句要用「-았/었을 거예요」。
    The result clause takes -았/었을 거예요.

例句

조금만 일찍 출발했더라면 늦지 않았을 거예요.
要是早一點出發就不會遲到了。
If we had left a little earlier, we wouldn't have been late.
그때 네 말을 들었더라면 좋았을 텐데.
那時候要是聽你的話就好了。
If only I had listened to you then.
네가 도와주지 않았더라면 큰일 날 뻔했어.
要是你沒幫忙，就出大事了。
If you hadn't helped, it would have been a disaster.
