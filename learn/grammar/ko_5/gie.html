V/A-기에 ／ N(이)기에

因為～（書面）；在～看來

as …, since … (written); for … — Korean grammar, Level 5

接續

動詞・形容詞語幹 ＋ -기에（過去 -았/었기에）　名詞 ＋ (이)기에
verb / adjective stem + -기에 (past -았/었기에)　noun + (이)기에

說明

書面、正式地說明原因：날씨가 맑기에 산책을 나갔다（因為天氣晴朗，出門散步）、모두가 반대했기에 계획을 바꾸었다（因為大家都反對，改了計畫）。「제가 보기에」是「在我看來」的固定說法。

A written, formal way to give a reason: 날씨가 맑기에 산책을 나갔다 (as the weather was clear, I went for a walk), 모두가 반대했기에 계획을 바꾸었다 (as everyone objected, we changed the plan). 제가 보기에 is a set phrase: "in my view".

注意事項

  • 意思和「-길래」相近，「-기에」較書面；後句不能是命令、勸誘。
    Close to -길래 but more formal; no command or suggestion after it.
  • 「-기에 + 形容詞」還可以表示「拿來做～的話」：혼자 하기에 너무 어려워요。
    -기에 + adjective can also mean "for doing …": 혼자 하기에 너무 어려워요.

常見錯誤

  • ✗ 시간이 없기에 빨리 가세요.
    ✓ 시간이 없으니까 빨리 가세요.
    後句是命令時，用「-(으)니까」。
    Before a command use -(으)니까.
  • ✗ 비가 오기에서 집에 있었다.
    ✓ 비가 오기에 집에 있었다.
    形式是「-기에」。
    The form is -기에.

例句

날씨가 맑기에 오랜만에 산책을 나갔다.
因為天氣晴朗，久違地出門散步。
As the weather was clear, I went for a walk for the first time in a while.
모두가 반대했기에 계획을 바꾸었다.
因為大家都反對，改了計畫。
As everyone objected, we changed the plan.
제가 보기에 이 방법이 더 좋은 것 같아요.
在我看來，這個方法比較好。
In my view, this way seems better.
