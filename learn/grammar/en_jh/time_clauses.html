when・before・after・if

時間和條件子句：when、before、after、if

Clauses with when, before, after, if — English grammar, junior high

接續

when／before／after／if ＋ 句子，＋ 主要句子　未來的事：子句用現在式（If it rains tomorrow, …）
when / before / after / if + clause, + main clause · for the future the clause uses the present (If it rains tomorrow, …)

說明

when（當…時）、before（在…之前）、after（在…之後）、if（如果）帶出一個子句，可以放前面（加逗號）或後面。說未來的事時，子句裡用現在式代替未來式：If it rains tomorrow, we will stay home.

when, before, after and if start a clause that can go first (with a comma) or second. For the future, the clause uses the present, not will: If it rains tomorrow, we will stay home.

注意事項

  • 主要子句照樣用 will：I'll call you when I arrive.
    The main clause still uses will: I'll call you when I arrive.

常見錯誤

  • ✗ If it will rain tomorrow, we will stay home.
    ✓ If it rains tomorrow, we will stay home.
    if 子句用現在式表示未來。
    The if clause uses the present for the future.
  • ✗ I'll call you when I will get home.
    ✓ I'll call you when I get home.
    when 子句也用現在式。
    The when clause uses the present too.

例句

Wash your hands before you eat.
吃東西前要洗手。
When I was a child, I lived in Hsinchu.
我小時候住在新竹。
If you're free tomorrow, let's go hiking.
如果你明天有空，我們去爬山吧。
