文法 › 法文 A2

le mien・la tienne・les nôtres …（所有代名詞）

我的（那個）、你的（那個）

possessive pronouns: mine, yours… — French grammar, A2

接續

le mien / la mienne / les miens / les miennes；le tien…；le sien…；le nôtre / la nôtre / les nôtres；le vôtre…；le leur / la leur / les leurs
le mien / la mienne / les miens / les miennes; le tien…; le sien…; le nôtre / les nôtres; le vôtre…; le leur / les leurs

說明

代替「所有格＋名詞」，避免重複：Ce n'est pas mon stylo, c'est le tien（這不是我的筆，是你的）。性別、數量配合被擁有的東西。

Replaces possessive + noun to avoid repeating it: Ce n'est pas mon stylo, c'est le tien (it's not my pen, it's yours). Agrees with the thing owned.

注意事項

  • nôtre、vôtre 有長音符號 ô。
    nôtre and vôtre have a circumflex.

常見錯誤

  • ✗ Ta voiture est rouge, le mien est bleu.
    ✓ Ta voiture est rouge, la mienne est bleue.
    voiture 是陰性，用 la mienne。
    voiture is feminine: la mienne.
  • ✗ Ce n'est pas mon stylo, c'est tien.
    ✓ Ce n'est pas mon stylo, c'est le tien.
    要有冠詞 le。
    It needs the article le.

例句

Ce n'est pas mon stylo, c'est le tien.
這不是我的筆，是你的。
It's not my pen, it's yours.
Ta voiture est rouge, la mienne est bleue.
你的車是紅的，我的是藍的。
Your car is red; mine is blue.
Nos enfants jouent avec les leurs.
我們的孩子和他們的孩子一起玩。
Our children play with theirs.
