presente de subjuntivo

虛擬式現在時的變化

Forming the present subjunctive — Spanish grammar, B1

接續

yo 的現在式去掉 -o，換母音：-ar → -e（hable）、-er／-ir → -a（coma、viva）　不規則：ser → sea、ir → vaya、estar → esté、haber → haya、saber → sepa、dar → dé
yo present minus -o, swap the vowel: -ar → -e (hable), -er / -ir → -a (coma, viva) · irregular: sea, vaya, esté, haya, sepa, dé

說明

虛擬式表示希望、情緒、懷疑或還沒發生的事，大多出現在 que 後面。從 yo 的現在式開始變，所以 tener → tengo → tenga、hacer → hago → haga。

The subjunctive marks wishes, feelings, doubt and things that haven't happened, mostly after que. Build it from the yo form: tener → tengo → tenga, hacer → hago → haga.

注意事項

  • 變音動詞也跟著變：querer → quiera、poder → pueda（nosotros 不變：queramos）。
    Stem changes carry over: quiera, pueda (not in nosotros: queramos).

常見錯誤

  • ✗ Quiero que tú vienes.
    ✓ Quiero que tú vengas.
    querer que 後面用虛擬式 vengas。
    querer que takes the subjunctive: vengas.
  • ✗ Espero que sea bien.
    ✓ Espero que esté bien.
    「好不好」的狀態用 estar → esté。
    How someone is takes estar → esté.

例句

Quiero que me digas la verdad.
我要你跟我說實話。
I want you to tell me the truth.
Es necesario que todos lleguen a tiempo.
大家都必須準時到。
Everyone needs to arrive on time.
Espero que tengas un buen viaje.
祝你旅途愉快。
I hope you have a good trip.
