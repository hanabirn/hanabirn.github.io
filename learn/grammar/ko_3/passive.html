V-이/히/리/기-（피동）

被動（被～、～得到）

passive verbs — Korean grammar, Level 3

接續

動詞語幹 ＋ 이/히/리/기：보다 → 보이다、먹다 → 먹히다、열다 → 열리다、안다 → 안기다　（하다動詞 → 되다：사용하다 → 사용되다）
verb stem + 이/히/리/기: 보다 → 보이다, 먹다 → 먹히다, 열다 → 열리다, 안다 → 안기다　(하다 verbs → 되다: 사용하다 → 사용되다)

說明

主語承受動作，或「自然地」發生：창문이 열렸어요（窗戶開了）、산이 보여요（看得到山）、모기한테 물렸어요（被蚊子咬了）。動作者用「에게/한테」。

The subject undergoes the action, or it happens by itself: 창문이 열렸어요 (the window opened), 산이 보여요 (you can see the mountain), 모기한테 물렸어요 (I got bitten by a mosquito). The doer takes 에게/한테.

注意事項

  • 要接哪個「이/히/리/기」是固定的，要一個一個記：놓다→놓이다、닫다→닫히다、팔다→팔리다、쫓다→쫓기다。
    Which suffix a verb takes must be learned: 놓이다, 닫히다, 팔리다, 쫓기다.

常見錯誤

  • ✗ 문이 닫았어요.
    ✓ 문이 닫혔어요.
    門（自己）關上用被動詞「닫히다」。
    “The door closed” uses the passive 닫히다.
  • ✗ 모기가 물렸어요.
    ✓ 모기한테 물렸어요.
    動作者（蚊子）用「한테/에게」。
    The doer (the mosquito) takes 한테/에게.

例句

바람 때문에 문이 닫혔어요.
因為風，門關上了。
The door shut because of the wind.
여기서 남산타워가 잘 보여요.
從這裡能清楚看到南山塔。
You can see Namsan Tower well from here.
어젯밤에 모기한테 많이 물렸어요.
昨晚被蚊子咬了好多包。
I got bitten a lot by mosquitoes last night.
