V-도록

為了讓～、以便～；直到～

so that …; until … — Korean grammar, Level 3

接續

動詞語幹 ＋ 도록
verb stem + 도록

說明

① 為了讓某種結果發生：잘 들리도록 크게 말해 주세요（請說大聲一點，讓大家聽得到）。② 程度、時間到某個地步：밤새도록 이야기했어요（聊了一整夜）。

① So that a result happens: 잘 들리도록 크게 말해 주세요 (please speak up so everyone can hear). ② To the point of: 밤새도록 이야기했어요 (we talked all night).

注意事項

  • 「-도록 하다」＝要做到～（指示）：늦지 않도록 하세요（請不要遲到）。
    -도록 하다 = make sure to: 늦지 않도록 하세요.

常見錯誤

  • ✗ 감기에 걸리지 않게도록 조심하세요.
    ✓ 감기에 걸리지 않도록 조심하세요.
    直接用「-지 않도록」。
    Simply -지 않도록.
  • ✗ 잘 들렸도록 크게 말해 주세요.
    ✓ 잘 들리도록 크게 말해 주세요.
    「-도록」前面不用過去式。
    No past tense before -도록.

例句

뒤에서도 잘 들리도록 크게 말해 주세요.
請說大聲一點，讓後面的人也聽得到。
Please speak up so people at the back can hear.
감기에 걸리지 않도록 조심하세요.
小心別感冒了。
Take care not to catch a cold.
친구와 밤새도록 이야기했어요.
和朋友聊了一整夜。
I talked with my friend all night long.
