elles se sont lavé les mains

反身動詞的過去分詞配合

Participle agreement with pronominal verbs — French grammar, B2

接續

se 是直接受詞 → 分詞配合（elle s'est lavée）・se 是間接受詞（後面另有直接受詞，或 se parler／se téléphoner）→ 不配合（elle s'est lavé les mains）
se is the direct object → agree (elle s'est lavée) · se is indirect (another direct object follows, or se parler / se téléphoner) → no agreement (elle s'est lavé les mains)

說明

反身動詞雖然用 être，配合規則卻跟 avoir 一樣，看 se 是不是直接受詞：Elle s'est coupée.（她割傷了自己。）Elle s'est coupé le doigt.（她割傷了手指，直接受詞是 le doigt。）Ils se sont parlé.（parler à：間接）

Pronominal verbs use être but agree like avoir verbs — it depends on whether se is the direct object: Elle s'est coupée. Elle s'est coupé le doigt (le doigt is the object). Ils se sont parlé (parler à: indirect).

注意事項

  • 常見的「不配合」：se parler、se téléphoner、se dire、se demander、se sourire。
    Common no-agreement verbs: se parler, se téléphoner, se dire, se demander, se sourire.

常見錯誤

  • ✗ Elles se sont téléphonées hier.
    ✓ Elles se sont téléphoné hier.
    téléphoner à：se 是間接受詞，不配合。
    téléphoner à: se is indirect, no agreement.
  • ✗ Marie s'est lavée les cheveux.
    ✓ Marie s'est lavé les cheveux.
    後面有直接受詞 les cheveux，分詞不配合。
    les cheveux is the direct object: no agreement.

例句

Elles se sont rencontrées à l'université.
她們是在大學認識的。
They met at university.
Nous nous sommes écrit pendant des années.
我們通信了好幾年。
We wrote to each other for years.
Elle s'est brossé les dents avant de dormir.
她睡前刷了牙。
She brushed her teeth before going to sleep.
