ça se mange froid

反身動詞表示被動：ça se mange froid

Pronominal verbs with a passive meaning — French grammar, B2

接續

東西 ＋ se ＋ 第三人稱動詞（一般會怎樣被…）：Ce plat se mange froid.・Ça ne se dit pas.
thing + se + third-person verb (how it's usually done): Ce plat se mange froid. · Ça ne se dit pas.

說明

用反身動詞說「一般會怎樣被做」或規範：Ce vin se boit frais.（這款酒要冰著喝。）Ça ne se fait pas !（這樣做不禮貌！）Le français se parle dans plusieurs pays.

A pronominal verb says how something is usually done or what's acceptable: Ce vin se boit frais. Ça ne se fait pas ! Le français se parle dans plusieurs pays.

注意事項

  • 主詞多是東西，動詞用第三人稱。
    The subject is usually a thing, with a third-person verb.

常見錯誤

  • ✗ Ce mot ne s'écrit pas comme ça se.
    ✓ Ce mot ne s'écrit pas comme ça.
    se 只出現一次，放在動詞前面。
    se appears once, before the verb.
  • ✗ Les crêpes se mange chaudes.
    ✓ Les crêpes se mangent chaudes.
    主詞是複數，動詞也要複數。
    A plural subject takes a plural verb.

例句

Ce gâteau se conserve trois jours au frigo.
這個蛋糕可以冷藏保存三天。
This cake keeps for three days in the fridge.
Comment ça se prononce ?
這個怎麼唸？
How do you pronounce that?
Ces chaussures se vendent très bien.
這雙鞋賣得很好。
These shoes sell very well.
