文法 › 德文 B1

wird wohl …・dürfte

推測：wird wohl、könnte、müsste

Guessing: wird wohl, könnte, müsste — German grammar, B1

接續

werden ＋ wohl ＋ 原形（大概）・muss（一定）・dürfte／müsste（應該）・könnte（可能）・kann nicht（不可能）
werden + wohl + infinitive (probably) · muss (must) · dürfte / müsste (should) · könnte (might) · kann nicht (can't)

說明

對現在的事做推測：Er wird wohl krank sein.（他大概生病了。）Das muss der Postbote sein.（那一定是郵差。）Sie könnte noch im Büro sein.（她可能還在辦公室。）

Guesses about the present: Er wird wohl krank sein. Das muss der Postbote sein. Sie könnte noch im Büro sein.

注意事項

  • 把握程度：muss ＞ dürfte／müsste ＞ wird wohl ＞ könnte。
    Certainty: muss > dürfte / müsste > wird wohl > könnte.

常見錯誤

  • ✗ Er wird wohl zu Hause ist.
    ✓ Er wird wohl zu Hause sein.
    werden 後面用原形 sein。
    werden takes the infinitive: sein.
  • ✗ Das kann nicht stimmt.
    ✓ Das kann nicht stimmen.
    情態動詞後面用原形。
    Modals take the infinitive.

例句

Es klingelt. Das wird wohl Anna sein.
門鈴響了，大概是安娜吧。
The doorbell's ringing. That'll be Anna.
Er sieht müde aus. Er muss lange gearbeitet haben.
他看起來很累，一定是工作了很久。
He looks tired. He must have worked late.
Das Paket dürfte morgen ankommen.
包裹應該明天會到。
The parcel should arrive tomorrow.
