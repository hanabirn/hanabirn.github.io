文法 › 德文 B1

wird gemacht

被動語態（現在式）

The passive (present) — German grammar, B1

接續

werden（變化）＋ … ＋ 過去分詞（句尾）　做的人：von ＋ 第三格
werden (conjugated) + … + past participle (end) · the doer: von + dative

說明

重點在「被做的事」而不是誰做時用被動：Hier wird Deutsch gesprochen.（這裡說德文。）Das Haus wird renoviert.（房子正在整修。）要說出是誰做的用 von：Das Essen wird von meinem Vater gekocht.

Use the passive when what happens matters more than who does it: Hier wird Deutsch gesprochen. Das Haus wird renoviert. Name the doer with von: Das Essen wird von meinem Vater gekocht.

注意事項

  • 沒有主詞時可以只用 es 或省略：Am Sonntag wird nicht gearbeitet.
    Without a subject: Am Sonntag wird nicht gearbeitet.

常見錯誤

  • ✗ Das Auto wird von der Werkstatt reparieren.
    ✓ Das Auto wird von der Werkstatt repariert.
    被動語態用過去分詞 repariert，不用原形。
    The passive uses the past participle, not the infinitive.
  • ✗ Die Briefe wird morgen verschickt.
    ✓ Die Briefe werden morgen verschickt.
    Briefe 是複數，用 werden。
    Briefe is plural: werden.

例句

In Taiwan wird viel Tee getrunken.
台灣人喝很多茶。
A lot of tea is drunk in Taiwan.
Die Fenster werden jeden Freitag geputzt.
窗戶每個星期五都會擦。
The windows are cleaned every Friday.
Das Museum wird um zehn Uhr geöffnet.
博物館十點開門。
The museum is opened at ten.
