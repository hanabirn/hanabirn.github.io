文法 › 日文 N5

V ます形 ＋ たいです

想做～

want to do … — Japanese grammar, N5

接續

動詞ます形（去掉ます）＋ たいです
verb stem (drop ます) + たいです

說明

把「～ます」的「ます」換成「たい」就是「想做～」：いきます → いきたいです（想去）。「たい」變化跟い形容詞一樣：否定「～たくないです」，過去「～たかったです」。

Replace ます with たい for “want to …”: いきます → いきたいです (I want to go). たい changes like an い-adjective: ～たくないです (don't want to), ～たかったです (wanted to).

注意事項

  • 對象可以用「を」也可以用「が」：すしを／が たべたいです。
    The object can take を or が: すしを / が たべたいです.
  • 直接問長輩「～たいですか」不太禮貌，請客人時改說「～ませんか」。
    Asking a superior “～たいですか” directly is a bit blunt; for invitations use ～ませんか instead.

常見錯誤

  • ✗ にほんへ いくたいです。
    ✓ にほんへ いきたいです。
    「たい」接在ます形後面（いき），不接字典形（いく）。
    たい attaches to the ます stem (いき), not the dictionary form (いく).
  • ✗ たべたいじゃありません。
    ✓ たべたくないです。
    「たい」的否定是「たくない」。
    The negative of たい is たくない.

例句

日本へ行きたいです。
にほんへ いきたいです。
想去日本。
I want to go to Japan.
すしが食べたいです。
すしが たべたいです。
想吃壽司。
I want to eat sushi.
今日は何もしたくないです。
きょうは なにも したくないです。
今天什麼都不想做。
I don't want to do anything today.
