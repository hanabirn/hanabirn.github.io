文法 › 日文 N5

V た ことが あります

曾經～過

have (ever) done … — Japanese grammar, N5

接續

動詞た形 ＋ ことが あります
verb た-form + ことが あります

說明

「～た ことが あります」表示經驗「曾經做過」：ふじさんに のぼった ことが あります（爬過富士山）。た形的做法和て形一樣，只是把て換成た：のんで → のんだ、いって → いった。

～た ことが あります talks about experience: ふじさんに のぼった ことが あります (I've climbed Mt Fuji). The た-form is made like the て-form with た instead of て: のんで → のんだ, いって → いった.

注意事項

  • 沒有經驗就說「～た ことが ありません」。
    No experience: ～た ことが ありません.
  • 只講「昨天做了」這種一次的事用「～ました」，不用這個句型。
    For a single event (“I did it yesterday”), just use ～ました.

常見錯誤

  • ✗ きのう すしを たべた ことが あります。
    ✓ きのう すしを たべました。
    有具體時間（きのう）的一次動作不用「～たことがある」，那是說人生經驗的。
    A one-off event with a time (きのう) isn't an experience — just use ～ました.
  • ✗ にほんへ いく ことが あります。
    ✓ にほんへ いった ことが あります。
    想說「去過」要用た形；「いく ことが ある」是「有時會去」。
    “Have been” needs the た-form; いく ことが ある means “sometimes go”.

例句

富士山に登ったことがあります。
ふじさんに のぼった ことが あります。
我爬過富士山。
I've climbed Mt Fuji.
納豆を食べたことがありますか。
なっとうを たべた ことが ありますか。
你吃過納豆嗎？
Have you ever eaten natto?
まだ日本へ行ったことがありません。
まだ にほんへ いった ことが ありません。
我還沒去過日本。
I've never been to Japan yet.
