～い ＋ N ／ ～な ＋ N

形容詞接名詞

Adjectives before nouns — Japanese grammar, N5

接續

い形容詞 ＋ 名詞（おおきい いえ）　／　な形容詞 ＋ な ＋ 名詞（しずかな まち）
い-adj + noun (おおきい いえ)　/　な-adj + な + noun (しずかな まち)

說明

形容詞放在名詞前面修飾它：い形容詞直接接：おおきい いえ（大房子）；な形容詞要加「な」：しずかな まち（安靜的城鎮）。

To describe a noun, put the adjective in front: い-adjectives go straight before it — おおきい いえ (a big house); な-adjectives add な — しずかな まち (a quiet town).

注意事項

  • 名詞接名詞才用「の」：にほんの くるま。形容詞不用「の」。
    Only noun + noun uses の (にほんの くるま) — adjectives don't.

常見錯誤

  • ✗ おおきいの いえ
    ✓ おおきい いえ
    い形容詞直接接名詞，不加「の」。
    い-adjectives join the noun directly — no の.
  • ✗ しずか まち
    ✓ しずかな まち
    な形容詞接名詞時要加「な」。
    な-adjectives need な before a noun.

例句

大きい家に住んでいます。
おおきい いえに すんで います。
住在大房子裡。
I live in a big house.
静かな町が好きです。
しずかな まちが すきです。
喜歡安靜的城鎮。
I like quiet towns.
きれいな花ですね。
きれいな はなですね。
好漂亮的花呢。
What pretty flowers.
