文法 › 日文 N5

N や N（など）

～和～等等（舉例）

… and … (among others) — Japanese grammar, N5

接續

名詞 ＋ や ＋ 名詞（＋ など）
noun + や + noun (+ など)

說明

「や」也是「和」，但只是舉幾個例子，表示還有別的：りんごや バナナを かいました（買了蘋果、香蕉之類的）。最後常加「など（等等）」。

や is also “and”, but it only gives examples, implying there's more: りんごや バナナを かいました (I bought apples, bananas and so on). など (etc.) often ends the list.

注意事項

  • 「と」＝全部列出，「や」＝只舉例。
    と lists everything; や gives examples.

常見錯誤

  • ✗ りんごや バナナや など かいました。
    ✓ りんごや バナナなどを かいました。
    「など」直接接在最後一個名詞後面，前面不用再加「や」。
    など follows the last noun directly — no extra や before it.
  • ✗ かばんに なにが ありますか。―さいふや かぎです。
    ✓ かばんに なにが ありますか。―さいふと かぎです。
    如果包包裡只有這兩樣東西，要用「と」；用「や」會讓人以為還有別的。
    If those are the only two things in the bag, use と; や suggests there's more.

例句

りんごやバナナを買いました。
りんごや バナナを かいました。
買了蘋果、香蕉之類的。
I bought apples, bananas and so on.
机の上に本やノートなどがあります。
つくえの うえに ほんや ノートなどが あります。
桌上有書、筆記本等等。
There are books, notebooks and so on on the desk.
休みの日は掃除や洗濯をします。
やすみの ひは そうじや せんたくを します。
休假日會打掃、洗衣服什麼的。
On days off I clean, do the laundry and so on.
