なにか・だれか・どこか

什麼東西・某個人・某個地方

something, someone, somewhere — Japanese grammar, N5

接續

疑問詞 ＋ か
question word + か

說明

疑問詞後面加「か」就變成「某個～」：なにか（某個東西）、だれか（某人）、どこか（某處）。なにか たべますか（要吃點什麼嗎？）。

A question word + か means “some-”: なにか (something), だれか (someone), どこか (somewhere). なにか たべますか (do you want to eat something?).

注意事項

  • 「を」「が」通常省略：なにか（を）のみますか。
    を and が are usually dropped: なにか (を) のみますか.
  • 回答「なにか～か」的問題用「はい／いいえ」，不是說出東西。
    Questions with なにか are answered with はい / いいえ first.

常見錯誤

  • ✗ なにか たべますか。―すしです。
    ✓ なにか たべますか。―はい、すしを たべます。
    「なにか」問的是「要不要吃點東西」，先回答はい／いいえ。
    なにか asks whether, so answer はい / いいえ first.
  • ✗ なにを たべますか。―はい。
    ✓ なにを たべますか。―すしを たべます。
    「なにを」問「吃什麼」，要回答東西。
    なにを asks what, so name the thing.

例句

何か飲みますか。
なにか のみますか。
要喝點什麼嗎？
Would you like something to drink?
だれか来ましたよ。
だれか きましたよ。
有人來了喔。
Someone's here.
夏休みはどこか行きましたか。
なつやすみは どこか いきましたか。
暑假有去哪裡玩嗎？
Did you go anywhere in the summer holidays?
