used to V・be used to V-ing

used to 和 be used to

used to and be used to — English grammar, senior high

接續

used to ＋ 原形（以前常常…，現在不了）・be／get used to ＋ V-ing／名詞（習慣於…）
used to + verb (did in the past, not now) · be / get used to + verb-ing / noun (be accustomed to)

說明

used to ＋ 原形說過去的習慣或狀態：I used to live in Kaohsiung.（我以前住在高雄。）be used to ＋ V-ing 是「已經習慣」：I'm used to getting up early.（我習慣早起了。）get used to 是「漸漸習慣」。

used to + verb is a past habit or state: I used to live in Kaohsiung. be used to + -ing means “be accustomed to”: I'm used to getting up early. get used to means “become accustomed”.

注意事項

  • be used to 的 to 是介系詞，後面接 V-ing 或名詞。
    In be used to, to is a preposition: -ing or a noun follows.
  • 否定和疑問：didn't use to、Did you use to …?
    Negatives and questions: didn't use to, Did you use to …?

常見錯誤

  • ✗ I'm used to drive on the left.
    ✓ I'm used to driving on the left.
    be used to 後面接 V-ing。
    be used to takes -ing.
  • ✗ She use to play the piano.
    ✓ She used to play the piano.
    肯定句寫成 used to。
    In statements it's used to.

例句

There used to be a cinema on this street.
這條街以前有一間電影院。
It took me months to get used to the cold weather.
我花了好幾個月才習慣寒冷的天氣。
Did you use to have long hair?
你以前是長頭髮嗎？
