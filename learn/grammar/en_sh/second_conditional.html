If I were …, I would …

與現在事實相反的假設

Unreal present: If I were …, I would … — English grammar, senior high

接續

If ＋ 主詞 ＋ 過去式（be 一律 were）, 主詞 ＋ would／could／might ＋ 原形
If + subject + past simple (be → were), subject + would / could / might + verb

說明

說「現在不是這樣，如果是的話會…」：If I had more time, I would learn to swim.（如果我有更多時間，就會去學游泳。）實際上我沒有時間。be 動詞不分人稱都用 were：If I were you, I'd apologize.

For situations that aren't true now: If I had more time, I would learn to swim (but I don't). be is were for every subject: If I were you, I'd apologize.

注意事項

  • 跟「真的可能發生」的條件不同：If it rains, I'll stay home.（有可能下雨）
    Compare a real possibility: If it rains, I'll stay home.

常見錯誤

  • ✗ If I am rich, I would buy a house.
    ✓ If I were rich, I would buy a house.
    與現在事實相反，if 子句用過去式 were。
    Unreal present: were in the if clause.
  • ✗ If I knew the answer, I will tell you.
    ✓ If I knew the answer, I would tell you.
    主要子句用 would，不用 will。
    The main clause takes would, not will.

例句

If I lived closer to school, I wouldn't have to get up so early.
如果我住得離學校近一點，就不用這麼早起了。
What would you do if you won the lottery?
如果你中了樂透，你會做什麼？
If I were you, I would take the job.
如果我是你，我會接下那份工作。
