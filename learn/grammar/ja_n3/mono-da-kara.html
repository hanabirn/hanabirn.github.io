普通形 ＋ ものだから／もので／もん

因為～嘛（辯解）

because … (giving an excuse) — Japanese grammar, N3

接續

普通形（な形容詞＋な／名詞＋な）＋ ものだから／もので（口語：もんだから・もん）
plain form (な-adj + な / noun + な) + ものだから / もので (casual もんだから, もん)

說明

說明自己不得已的理由，常用於道歉或辯解：道が こんで いた ものだから、遅れて しまいました（因為路上塞車，所以遲到了）。句尾的「～もん」是撒嬌式的理由：だって、眠いんだもん（因為人家很睏嘛）。

Gives an excuse, often when apologising: 道が こんで いた ものだから、遅れて しまいました (the roads were jammed, so I'm late). Sentence-final ～もん is a childish “because”: だって、眠いんだもん (but I'm sleepy!).

注意事項

  • 後面不接命令、請求等；只用來解釋。
    Not followed by orders or requests — it only explains.

常見錯誤

  • ✗ 時間が ない ものだから、早く して ください。
    ✓ 時間が ないので、早く して ください。
    後面是請求時用「ので」，不用「ものだから」。
    Before a request use ので, not ものだから.
  • ✗ 子どもの ものだから、許して ください。
    ✓ 子どもな ものですから、許して ください。
    名詞接「な ものだから」。
    A noun takes な before ものだから.

例句

道が混んでいたものですから、遅れてしまいました。
みちが こんで いた もの ですから、おくれて しまいました。
因為路上塞車，所以遲到了。
The roads were jammed, so I'm afraid I'm late.
急いでいたもので、連絡するのを忘れました。
いそいで いた もので、れんらくするのを わすれました。
因為太趕了，忘了跟你聯絡。
I was in a rush, so I forgot to get in touch.
「なんで食べないの？」「だって、まずいんだもん。」
「なんで たべないの？」「だって、まずいんだもん。」
「為什麼不吃？」「因為很難吃嘛。」
“Why aren't you eating?” “Because it's yucky!”
