N こそ

正是～、才是～

(it's) precisely … — Japanese grammar, N3

接續

名詞 ＋ こそ　／　～から こそ（正因為～）
noun + こそ　/　～から こそ (precisely because)

說明

強調「就是這個」：今年こそ 合格したい（今年一定要考上）。「から こそ」強調理由：好きだから こそ きびしく する（正因為喜歡才嚴格）。

Stresses “this one and no other”: 今年こそ 合格したい (this year I'm going to pass). から こそ stresses the reason: 好きだから こそ きびしく する (it's because I care that I'm strict).

注意事項

  • 「こちらこそ」是寒暄：我才要（謝謝你／請多指教）。
    こちらこそ is the set reply “likewise / the pleasure's mine”.

常見錯誤

  • ✗ 今年が こそ 合格したい。
    ✓ 今年こそ 合格したい。
    「こそ」取代「が」「は」。
    こそ replaces が / は.
  • ✗ 好きで こそ、きびしく する。
    ✓ 好きだから こそ、きびしく する。
    強調理由用「から こそ」。
    A stressed reason is から こそ.

例句

今年こそN3に合格したい。
ことしこそ エヌさんに ごうかくしたい。
今年一定要考過N3。
This year, I'm going to pass N3.
「よろしくお願いします。」「こちらこそ。」
「よろしく おねがいします。」「こちらこそ。」
「請多指教。」「我才要請你多指教。」
“Nice to work with you.” “Likewise.”
あなたのことが大切だからこそ、厳しく言うのです。
あなたの ことが たいせつだから こそ、きびしく いうのです。
正因為在乎你，我才說得這麼嚴厲。
It's precisely because I care about you that I'm being strict.
