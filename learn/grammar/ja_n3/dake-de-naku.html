文法 › 日文 N3

～だけで なく／～ばかりで なく

不只～還～

not only … but also … — Japanese grammar, N3

接續

普通形（な形容詞＋な／名詞）＋ だけで なく／ばかりで なく ＋ ～も
plain form (な-adj + な / noun) + だけで なく / ばかりで なく + ～も

說明

除了前面的，還有後面的：この 歌は 子どもだけで なく、大人にも 人気が ある（這首歌不只小孩，大人也很喜歡）。後半常用「も」。

Besides the first, the second too: この 歌は 子どもだけで なく、大人にも 人気が ある (this song is popular with adults as well as children). The second part often has も.

注意事項

  • 口語說「～だけじゃ なくて」。
    Casually ～だけじゃ なくて.

常見錯誤

  • ✗ かれは 英語だけで なく、中国語は 話せる。
    ✓ かれは 英語だけで なく、中国語も 話せる。
    後面要用「も」表示追加。
    Use も for the added item.
  • ✗ この 部屋は 広いだけ なく、明るい。
    ✓ この 部屋は 広いだけで なく、明るい。
    固定說法是「だけで なく」。
    The phrase is だけで なく.

例句

この歌は子どもだけでなく、大人にも人気がある。
この うたは こどもだけで なく、おとなにも にんきが ある。
這首歌不只小孩，大人也很喜歡。
This song is popular not only with children but with adults too.
彼は英語だけでなく、フランス語も話せる。
かれは えいごだけで なく、フランスごも はなせる。
他不只會說英文，也會說法文。
He speaks not only English but French too.
この部屋は広いだけでなく、日当たりもいい。
この へやは ひろいだけで なく、ひあたりも いい。
這房間不只寬敞，採光也很好。
This room is not only spacious but also sunny.
