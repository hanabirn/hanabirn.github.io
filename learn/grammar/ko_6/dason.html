V/A-다손 치더라도

就算假設～，也～

even granting that … — Korean grammar, Level 6

接續

形容詞 → -다손 치더라도　動詞 → -ㄴ/는다손 치더라도　名詞 → N(이)라손 치더라도
adjectives → -다손 치더라도　verbs → -ㄴ/는다손 치더라도　nouns → N(이)라손 치더라도

說明

退一步承認前面的事，後面的結論仍然不變：그게 사실이라손 치더라도 그렇게 말하면 안 돼요（就算那是事實，也不能那樣說）、아무리 바쁘다손 치더라도 전화 한 통은 할 수 있잖아요（再怎麼忙，打一通電話總可以吧）。

Grants the first point for argument's sake; the conclusion still stands: 그게 사실이라손 치더라도 그렇게 말하면 안 돼요 (even if that were true, you shouldn't say it like that), 아무리 바쁘다손 치더라도 전화 한 통은 할 수 있잖아요 (however busy you are, you could make one call).

注意事項

  • 書面；意思接近「-다고 하더라도」。
    Written; close to -다고 하더라도.
  • 動詞現在用「-ㄴ/는다손」：온다손、먹는다손。
    Verbs in the present take -ㄴ/는다손: 온다손, 먹는다손.

常見錯誤

  • ✗ 그게 사실이다손 치더라도 그렇게 말하면 안 돼요.
    ✓ 그게 사실이라손 치더라도 그렇게 말하면 안 돼요.
    名詞接「(이)라손」。
    Nouns take (이)라손.
  • ✗ 아무리 바쁘다손 치더라도 연락을 했어요.
    ✓ 아무리 바쁘다손 치더라도 연락은 했어야지요.
    後句是「仍然應該～」的結論。
    The second clause is what should still hold.

例句

그게 사실이라손 치더라도 그렇게 말하면 안 돼요.
就算那是事實，也不能那樣說。
Even if that were true, you shouldn't say it like that.
아무리 바쁘다손 치더라도 전화 한 통은 할 수 있잖아요.
再怎麼忙，打一通電話總可以吧。
However busy you are, you could make one call.
지금 출발한다손 치더라도 제시간에 도착하기는 어렵다.
就算現在出發，也很難準時到。
Even if we set off now, we'd hardly arrive on time.
