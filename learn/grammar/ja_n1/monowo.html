普通形 ＋ ものを

本來～就好了，卻～（遺憾、不滿）

if only …, when … (regret) — Japanese grammar, N1

接續

普通形（多為「～ば…ものを」）
plain form (often ～ば … ものを)

說明

表示「本來可以這樣做（就好了），實際卻沒有」，帶有遺憾、不滿、責備的語氣：早く言えばよかったものを（早點說就好了嘛）。

It could have been done but wasn't — with regret, discontent or reproach: 早く言えばよかったものを (you should have just said so).

注意事項

  • 常見「～ばいいものを」「～ばよかったものを」。
    Common as ～ばいいものを / ～ばよかったものを.
  • 句尾常省略後半，只留下不滿的語氣。
    The rest is often left out, leaving only the frustration.

常見錯誤

  • ✗ 早く言えばよかったものに。
    ✓ 早く言えばよかったものを。
    固定形式是「ものを」。
    The set form is ものを.

例句

早く言ってくれればよかったものを。
はやく いって くれれば よかった ものを。
早點跟我說就好了嘛。
If only you'd told me sooner.
黙っていればいいものを、余計なことを言うから怒られるんだ。
だまって いれば いい ものを、よけいな ことを いうから おこられるんだ。
安靜不說話就好了，偏偏多嘴，才會挨罵。
You could have kept quiet, but you said too much — that's why you got told off.
一言謝れば済むものを、彼は意地を張っている。
ひとこと あやまれば すむ ものを、かれは いじを はって いる。
道個歉就沒事了，他卻在逞強。
A single apology would settle it, yet he's being stubborn.
