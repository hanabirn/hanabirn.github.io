(кому) нужен・нужна・нужно・нужны ＋ N

（某人）需要～（東西）

(someone) needs (a thing) — Russian grammar, A2

接續

與格（人）＋ нужен／нужна／нужно／нужны ＋ 主格（東西）——形式跟著「東西」的性別、數量
dative (person) + нужен / нужна / нужно / нужны + nominative (thing) — agreeing with the thing

說明

Мне нужен зонт（我需要一把傘）、Ей нужна помощь（她需要幫助）、Нам нужны деньги（我們需要錢）。A1 學過「надо／нужно ＋ 原形（需要做）」，這裡是需要「東西」。

Мне нужен зонт (I need an umbrella), Ей нужна помощь (she needs help), Нам нужны деньги (we need money). A1 had надо / нужно + infinitive (need to do); this is needing a thing.

注意事項

  • 被需要的東西是主語（主格），人是與格。
    The thing is the subject (nominative); the person is dative.

常見錯誤

  • ✗ Мне нужно зонт.
    ✓ Мне нужен зонт.
    зонт 是陽性，用 нужен。
    зонт is masculine: нужен.
  • ✗ Я нужна помощь.
    ✓ Мне нужна помощь.
    人用與格 мне。
    The person is dative: мне.

例句

Мне нужен новый телефон.
Мне ну́жен но́вый телефо́н.
我需要一支新手機。
I need a new phone.
Тебе нужна помощь?
Тебе́ нужна́ по́мощь?
你需要幫忙嗎？
Do you need help?
Для поездки нам нужны визы.
Для пое́здки нам нужны́ ви́зы.
這趟旅行我們需要簽證。
We need visas for the trip.
