Hanabiの小天地文法總覽
文法 › 俄文 A2

уже ／ ещё ／ уже не ／ ещё не

已經～／還～／不再～／還沒～

already / still / no longer / not yet — Russian grammar, A2

接續

уже（已經）　ещё（還）　уже не（已經不再）　ещё не（還沒）
уже (already)　ещё (still)　уже не (no longer)　ещё не (not yet)

說明

Он уже пришёл（他已經來了）、Она ещё спит（她還在睡）、Я уже не работаю там（我已經不在那裡工作了）、Я ещё не обедал（我還沒吃午餐）。

Он уже пришёл (he's already here), Она ещё спит (she's still asleep), Я уже не работаю там (I don't work there any more), Я ещё не обедал (I haven't had lunch yet).

注意事項

  • 「Ещё раз」＝再一次；「Ещё чаю?」＝再來點茶？
    Ещё раз = once more; Ещё чаю? = more tea?

常見錯誤

  • ✗ Я уже не обедал.
    ✓ Я ещё не обедал.
    「還沒」是 ещё не。
    “Not yet” is ещё не.
  • ✗ Она уже спит, не буди её.
    ✓ Она ещё спит, не буди её.
    「還在」用 ещё。
    “Still” is ещё.

例句

Он уже пришёл?
Он уже́ пришёл?
他已經來了嗎？
Is he here already?
Тише, ребёнок ещё спит.
Ти́ше, ребёнок ещё спит.
小聲點，孩子還在睡。
Shh, the baby's still asleep.
Я уже не живу в Москве.
Я уже́ не живу́ в Москве́.
我已經不住在莫斯科了。
I don't live in Moscow any more.
