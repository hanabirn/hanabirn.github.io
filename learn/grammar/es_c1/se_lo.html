doble pronombre: se lo / se la

雙重代名詞 se lo

Double object pronouns: se lo — Spanish grammar, C1

接續

間接受詞 ＋ 直接受詞；le／les 在 lo, la, los, las 前面變成 se：Le doy el libro → Se lo doy
indirect + direct object; le / les become se before lo, la, los, las: Le doy el libro → Se lo doy

說明

兩個代名詞一起出現時，間接受詞在前；le／les 遇到 lo／la／los／las 一律變成 se。代名詞放在變位動詞前，或接在不定式、副動詞、肯定命令式後面：Dáselo. Voy a decírselo.

With two pronouns the indirect one comes first, and le / les always become se before lo / la / los / las. They go before a finite verb or attach to an infinitive, gerund or affirmative command: Dáselo. Voy a decírselo.

注意事項

  • 接在動詞後面時常要加重音符號以保持重音：dándoselo, explícaselo。
    Attached pronouns often need an accent to keep the stress: dándoselo, explícaselo.

常見錯誤

  • ✗ Le lo expliqué ayer.
    ✓ Se lo expliqué ayer.
    le ＋ lo → se lo。
    le + lo → se lo.
  • ✗ Dalo se a tu hermano.
    ✓ Dáselo a tu hermano.
    肯定命令式：代名詞接在後面，加重音。
    Affirmative command: attach and add the accent.

例句

¿Las llaves? Ya se las di a Marta.
鑰匙？我已經給瑪塔了。
The keys? I’ve already given them to Marta.
Si quiere el informe, se lo envío esta tarde.
如果您要報告，我今天下午寄給您。
If you want the report, I’ll send it to you this afternoon.
Estoy explicándoselo ahora mismo.
我現在正在跟他解釋。
I’m explaining it to him right now.
