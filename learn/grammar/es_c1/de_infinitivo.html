文法 › 西班牙文 C1

de + infinitivo (condición)

de＋不定式表示條件

de + infinitive as a condition — Spanish grammar, C1

接續

De ＋ 不定式 ＝ si ＋ 動詞；De ＋ haber ＋ 過去分詞 ＝ si ＋ 虛擬式過去完成時
De + infinitive = si + verb; De + haber + participle = si + pluperfect subjunctive

說明

書面和正式口語中，用 de ＋ 不定式代替 si 子句：De saberlo, te lo diría.（如果我知道，就會告訴你。）De haberlo sabido, habría venido.（早知道的話，我就來了。）

In writing and formal speech, de + infinitive replaces an si clause: De saberlo, te lo diría. De haberlo sabido, habría venido.

注意事項

  • 主詞通常和主句相同；不同時可在後面加主詞：De venir Juan, avísame.
    The subject is usually the main clause’s; otherwise add it after: De venir Juan, avísame.

常見錯誤

  • ✗ De lo haber sabido, no habría ido.
    ✓ De haberlo sabido, no habría ido.
    代名詞接在不定式後面：haberlo。
    The pronoun attaches to the infinitive: haberlo.
  • ✗ De tengo tiempo, iré.
    ✓ De tener tiempo, iré.
    de 後面用不定式。
    de takes the infinitive.

例句

De seguir así, perderemos el partido.
照這樣下去，我們會輸掉比賽。
If things go on like this, we’ll lose the match.
De haber salido antes, no habríamos perdido el tren.
如果早點出門，我們就不會錯過火車了。
If we had left earlier, we wouldn’t have missed the train.
De ser cierto, sería una gran noticia.
如果是真的，那會是個大新聞。
If it were true, it would be great news.
