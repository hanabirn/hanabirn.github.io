～ば（條件）

如果～就～（ば形）

if … (the ば form) — Japanese grammar, N4

接續

動詞：う段 → え段 ＋ ば（いく → いけば、たべる → たべれば）　い形容詞：～い → ～ければ　名詞・な形容詞：～なら（ば）
verbs: u → e + ば (いく → いけば, たべる → たべれば)　い-adj: ～い → ～ければ　nouns / な-adj: ～なら(ば)

說明

「～ば」表示前面的條件成立，後面的結果就會發生：ボタンを おせば、きっぷが でます（按下按鈕，票就會出來）、やすければ かいます（便宜的話就買）。

～ば says that if the condition holds, the result follows: ボタンを おせば、きっぷが でます (press the button and the ticket comes out), やすければ かいます (if it's cheap, I'll buy it).

注意事項

  • 「いい」的ば形是「よければ」：よければ どうぞ（不嫌棄的話請用）。
    The ば form of いい is よければ: よければ どうぞ (please, if you like).
  • 問建議：どう すれば いいですか（該怎麼做才好？）。
    Asking for advice: どう すれば いいですか (what should I do?).

常見錯誤

  • ✗ やすいば かいます。
    ✓ やすければ かいます。
    い形容詞要把い換成「ければ」。
    い-adjectives change い to ければ.
  • ✗ どう すると いいですか。
    ✓ どう すれば いいですか。
    問「怎麼做才好」固定用「すれば いい」。
    “What should I do” is すれば いい.

例句

ボタンを押せば、切符が出ます。
ボタンを おせば、きっぷが でます。
按下按鈕，票就會出來。
Press the button and the ticket comes out.
安ければ買います。
やすければ かいます。
便宜的話就買。
I'll buy it if it's cheap.
どうすればいいですか。
どう すれば いいですか。
該怎麼做才好呢？
What should I do?
