V る ように／V ない ように

為了能～、以免～

so that …, so as not to … — Japanese grammar, N4

接續

動詞字典形・可能形・ない形 ＋ ように、意志動作
verb dictionary / potential / ない form + ように, deliberate action

說明

為了達到某個狀態而做某事：よく みえるように、まえの せきに すわります（為了看清楚坐前面）、わすれないように、メモします（以免忘記先記下來）。前面通常是可能形、無意志動詞或否定。

Doing something so that a state is reached: よく みえるように、まえの せきに すわります (I sit at the front so I can see), わすれないように、メモします (I write it down so I don't forget). The first part is usually a potential form, a non-volitional verb or a negative.

注意事項

  • 「～ように して います」是「盡量做到」：まいにち やさいを たべるように して います（盡量每天吃蔬菜）。
    ～ように して います means “make a point of”: まいにち やさいを たべるように して います.
  • 「～ように いって ください」是轉達請求：はやく くるように いって ください。
    ～ように いって ください relays a request: はやく くるように いって ください.

常見錯誤

  • ✗ わすれない ために、メモします。
    ✓ わすれないように、メモします。
    「忘記」不是自己能控制的，否定的目的用「ように」。
    Forgetting isn't deliberate — use ように for “so as not to”.
  • ✗ よく みえる ために、まえに すわります。
    ✓ よく みえるように、まえに すわります。
    「みえる」是無意志動詞，用「ように」。
    みえる is non-volitional — use ように.

例句

よく見えるように、前の席に座ります。
よく みえるように、まえの せきに すわります。
為了看清楚，坐在前面的位子。
I sit at the front so I can see well.
忘れないように、メモしておきます。
わすれないように、メモして おきます。
以免忘記，先記下來。
I'll write it down so I don't forget.
毎日野菜を食べるようにしています。
まいにち やさいを たべるように して います。
我盡量每天吃蔬菜。
I make a point of eating vegetables every day.
