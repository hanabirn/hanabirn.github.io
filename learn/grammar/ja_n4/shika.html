N しか ～ない

只有～（覺得太少）

only … (and that's not much) — Japanese grammar, N4

接續

名詞・數量 ＋ しか ＋ 否定
noun / amount + しか + negative

說明

「しか～ない」是「只有」，帶有「太少、不夠」的感覺：さいふに せんえんしか ありません（錢包裡只剩一千日圓）。後面一定接否定。

しか～ない means “only”, with a feeling of “not enough”: さいふに せんえんしか ありません (I've only got 1,000 yen in my wallet). It always takes a negative.

注意事項

  • 「だけ」是中性的「只有」；「しか～ない」強調少。
    だけ is neutral “only”; しか～ない stresses how little.

常見錯誤

  • ✗ せんえんしか あります。
    ✓ せんえんしか ありません。
    「しか」後面一定接否定。
    しか always takes a negative.
  • ✗ ひらがなを しか よめません。
    ✓ ひらがなしか よめません。
    「しか」取代「を」「が」。
    しか replaces を / が.

例句

財布に千円しかありません。
さいふに せんえんしか ありません。
錢包裡只剩一千日圓。
I've only got 1,000 yen in my wallet.
ひらがなしか読めません。
ひらがなしか よめません。
我只看得懂平假名。
I can only read hiragana.
昨日は三時間しか寝ませんでした。
きのうは さんじかんしか ねませんでした。
昨天只睡了三小時。
I only slept three hours last night.
