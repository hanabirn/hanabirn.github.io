文法 › 日文 N4

N が V て あります

（被人）～著（刻意留下的狀態）

has been … (deliberately, state) — Japanese grammar, N4

接續

名詞 ＋ が ＋ 他動詞て形 ＋ あります
noun + が + transitive verb て-form + あります

說明

表示有人為了某個目的做了某件事，結果留了下來：かべに ちずが はって あります（牆上貼著地圖）、ビールは もう かって あります（啤酒已經買好了）。用的是他動詞（はる、かう、おく）。

Someone did something on purpose and the result remains: かべに ちずが はって あります (a map has been put up on the wall), ビールは もう かって あります (the beer's already been bought). It uses transitive verbs (はる, かう, おく).

注意事項

  • 比較：まどが あいて います（窗戶開著，單純描述）／まどが あけて あります（窗戶被打開了，有人為了通風刻意打開）。
    Compare: まどが あいて います (the window is open — just a description) / まどが あけて あります (someone opened it on purpose).

常見錯誤

  • ✗ かべに ちずを はって あります。
    ✓ かべに ちずが はって あります。
    「～て ある」通常用「が」標出那個東西。
    With ～て ある the thing usually takes が.
  • ✗ まどが あいて あります。
    ✓ まどが あけて あります。
    「～て ある」要用他動詞（あける），不用自動詞（あく）。
    ～て ある needs a transitive verb (あける), not intransitive (あく).

例句

壁に地図がはってあります。
かべに ちずが はって あります。
牆上貼著地圖。
A map has been put up on the wall.
ビールはもう買ってあります。
ビールは もう かって あります。
啤酒已經買好了。
The beer has already been bought.
テーブルの上に花が飾ってあります。
テーブルの うえに はなが かざって あります。
桌上擺著花。
Flowers have been placed on the table.
