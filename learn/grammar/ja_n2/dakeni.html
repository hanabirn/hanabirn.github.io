普通形 ＋ だけに

正因為～（所以更加～）

precisely because … (all the more) — Japanese grammar, N2

接續

動詞・い形容詞普通形／な形容詞＋な／名詞（＋である）＋ だけに
plain verb / い-adj, な-adj + な, noun (+ である) + だけに

說明

表示「正因為是那樣的情況，所以結果更加～」，後面接和前面相稱、或因此更強烈的結果與感受：期待していただけに、がっかりした（正因為很期待，所以更失望）。

Precisely because of the situation before it, the result is fitting or all the stronger: 期待していただけに、がっかりした (because I had hoped so much, I was all the more disappointed).

注意事項

  • 「～だけあって」只用在正面評價（不愧是～）；「だけに」好壞結果都能用。
    ～だけあって is only for praise (as you would expect of …); だけに works for good and bad results.
  • 不是 N5 的「だけ（只有）」：「だけに」後面會接一個結果句。
    Not the だけ “only” of N5: だけに is followed by a result clause.

常見錯誤

  • ✗ 一生懸命練習しただけで、負けてとても悔しい。
    ✓ 一生懸命練習しただけに、負けてとても悔しい。
    「だけで」是「光是～就」；要表示「正因為～所以更加」用「だけに」。
    だけで means “just by …”; for “precisely because …, all the more” use だけに.

例句

期待していただけに、結果を見てがっかりした。
きたいして いた だけに、けっかを みて がっかりした。
正因為很期待，看到結果更失望了。
Because I had hoped so much, the result was all the more disappointing.
この店は駅前にあるだけに、いつも混んでいる。
この みせは えきまえに ある だけに、いつも こんで いる。
這家店正因為在車站前，總是很多人。
Being right in front of the station, this shop is always crowded.
ベテラン選手だけに、落ち着いてプレーしている。
ベテラン せんしゅ だけに、おちついて プレーして いる。
到底是老將，比賽時很沉著。
Being a veteran, he plays with composure.
