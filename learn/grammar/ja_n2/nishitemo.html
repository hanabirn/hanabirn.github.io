普通形／N ＋ にしても・にせよ・にしろ

即使～也～／不論～

even if …, whether … or … — Japanese grammar, N2

接續

普通形（名詞・な形容詞直接接或加「である」）＋ にしても／にせよ／にしろ
plain form (noun / な-adj bare or + である) + にしても / にせよ / にしろ

說明

「即使是那樣，也～」：理由があるにしても、無断欠席はよくない（就算有理由，無故缺席也不對）。重複成「AにせよBにせよ」表示「不論A還是B」：行くにしろ行かないにしろ、連絡してください。

“Even if …”: 理由があるにしても、無断欠席はよくない (even if there was a reason, skipping without notice is wrong). Doubled — A にせよ B にせよ — it means “whether A or B”: 行くにしろ行かないにしろ、連絡してください.

注意事項

  • 「にせよ」「にしろ」比「にしても」更書面、更硬。
    にせよ and にしろ are stiffer and more written than にしても.
  • 常用說法：いずれにせよ／いずれにしても（不管怎樣）。
    Set phrase: いずれにせよ / いずれにしても (in any case).

常見錯誤

  • ✗ 行くにしろ行かないにも、連絡してください。
    ✓ 行くにしろ行かないにしろ、連絡してください。
    前後要用同一個形式：「～にしろ～にしろ」。
    Use the same form twice: ～にしろ～にしろ.

例句

理由があるにしても、無断で休むのはよくない。
りゆうが あるに しても、むだんで やすむのは よくない。
就算有理由，擅自請假也不對。
Even if you had a reason, taking time off without notice is wrong.
行くにしろ行かないにしろ、早めに連絡してください。
いくに しろ いかないに しろ、はやめに れんらく して ください。
不管去不去，請早點聯絡。
Whether you go or not, please let us know early.
いずれにせよ、もう一度話し合う必要がある。
いずれに せよ、もう いちど はなしあう ひつようが ある。
不管怎樣，都有必要再談一次。
Either way, we need to talk it over again.
