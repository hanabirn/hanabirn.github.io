чтобы・для того чтобы ＋ 原形

為了……

In order to (чтобы, для того чтобы) — Russian grammar, B2

接續

主詞相同：чтобы／для того чтобы ＋ 原形；主詞不同：чтобы ＋ 過去式
Same subject: чтобы / для того чтобы + infinitive; different subject: чтобы + past tense

說明

表示目的：Я учу русский, чтобы читать Толстого.（我學俄文是為了讀托爾斯泰。）兩個子句主詞不同時，чтобы 後面用過去式：Я говорю медленно, чтобы ты понял.

States a purpose: Я учу русский, чтобы читать Толстого. With different subjects чтобы takes the past tense: Я говорю медленно, чтобы ты понял.

注意事項

  • для того чтобы 比 чтобы 正式，常見於書面語。
    для того чтобы is more formal than чтобы, typical of writing.

常見錯誤

  • ✗ Я пришёл, чтобы ты помогаешь мне.
    ✓ Я пришёл, чтобы ты помог мне.
    主詞不同時 чтобы 後面用過去式。
    Different subjects: чтобы + past tense.
  • ✗ Он работает, для того купить машину.
    ✓ Он работает, для того чтобы купить машину.
    要說 для того чтобы。
    It is для того чтобы.

例句

Я встал рано, чтобы успеть на поезд.
Я встал ра́но, что́бы успе́ть на по́езд.
我早起是為了趕上火車。
I got up early to catch the train.
Мама купила продукты, чтобы мы приготовили ужин.
Ма́ма купи́ла проду́кты, что́бы мы пригото́вили у́жин.
媽媽買了食材，讓我們做晚餐。
Mum bought food so that we could cook dinner.
Для того чтобы получить визу, нужен паспорт.
Для того́ что́бы получи́ть ви́зу, ну́жен па́спорт.
要辦簽證需要護照。
To get a visa you need a passport.
