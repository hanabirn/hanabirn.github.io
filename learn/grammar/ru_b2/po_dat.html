по ＋ 與格（分配・規律）

每……、按……

по + dative (distribution, regularity) — Russian grammar, B2

接續

по ＋ 與格：по субботам（每週六）、по утрам（每天早上）；по ＋ 數詞：по одному яблоку、по два／по три ＋ 名詞（數詞用主格／賓格）
по + dative: по субботам, по утрам; по + numeral: по одному яблоку, по два / по три + noun (numeral in nominative / accusative)

說明

по ＋ 複數與格 表示「每逢……」的規律：По воскресеньям мы ходим в музей.（每週日我們去博物館。）表示分配「每人各……」：Дети получили по яблоку.（孩子們每人拿到一個蘋果。）

по + dative plural for something regular: По воскресеньям мы ходим в музей. For distribution, "each": Дети получили по яблоку (one apple each).

注意事項

  • по 也表示途徑、方式：по телефону、по почте、по радио。
    по also gives the channel: по телефону, по почте, по радио.

常見錯誤

  • ✗ Мы гуляем в вечерах.
    ✓ Мы гуляем по вечерам.
    「每天傍晚」用 по ＋ 複數與格。
    "Every evening" is по + dative plural.
  • ✗ Каждый получил по три яблокам.
    ✓ Каждый получил по три яблока.
    по 後面的 два／три／четыре 不變成與格。
    After по, два / три / четыре stay in the accusative.

例句

По субботам у нас нет занятий.
По суббо́там у нас нет заня́тий.
我們週六沒有課。
We have no classes on Saturdays.
Учитель дал ученикам по две задачи.
Учи́тель дал ученика́м по две зада́чи.
老師給學生每人兩道題。
The teacher gave the pupils two problems each.
Мы долго говорили по телефону.
Мы до́лго говори́ли по телефо́ну.
我們講了很久的電話。
We talked on the phone for a long time.
