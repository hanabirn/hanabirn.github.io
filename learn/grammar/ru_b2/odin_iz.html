один из・любой・каждый

один из、любой、каждый

один из, любой, каждый — Russian grammar, B2

接續

один／одна／одно из ＋ 複數屬格（одна из лучших книг）・каждый（每一個）・любой（任何一個都行）
один / одна / одно из + genitive plural (одна из лучших книг) · каждый (every) · любой (any, whichever)

說明

「…之一」：Это один из самых красивых городов мира.（這是世界上最美的城市之一。）один 跟所指的名詞同性。любой 是「隨便哪一個都可以」，каждый 是「每一個」。

“One of”: Это один из самых красивых городов мира. один agrees with the noun meant. любой is “any you like”, каждый “each and every”.

注意事項

  • 「最…之一」常用最高級 -ейший：один из крупнейших городов。
    “One of the most …” often uses -ейший: один из крупнейших городов.

常見錯誤

  • ✗ Один из мой друг живёт в Казани.
    ✓ Один из моих друзей живёт в Казани.
    из 後面接複數屬格。
    из takes the genitive plural.
  • ✗ Это одна из лучших фильмов.
    ✓ Это один из лучших фильмов.
    фильм 是陽性，用 один。
    фильм is masculine: один.

例句

Это один из самых красивых городов мира.
Э́то оди́н из са́мых краси́вых городо́в ми́ра.
這是世界上最美的城市之一。
It's one of the most beautiful cities in the world.
Каждый день я гуляю с собакой.
Ка́ждый день я гуля́ю с соба́кой.
我每天都去遛狗。
I walk the dog every day.
Звони в любое время.
Звони́ в любо́е вре́мя.
隨時都可以打給我。
Call any time.
