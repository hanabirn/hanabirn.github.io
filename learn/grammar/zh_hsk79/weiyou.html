唯有 ～，才 ～

唯有：只有

唯有 … 才 — only (literary) — Chinese grammar, HSK 7–9

接續

唯有／惟有 ＋ 唯一條件，才 ＋ 結果
唯有 / 惟有 + the only condition, 才 + result

說明

書面語的「只有……才……」，強調這是唯一的條件：唯有不斷學習，才能跟上時代。

Literary 只有…才…, stressing the only condition: 唯有不斷學習，才能跟上時代.

注意事項

  • 「唯有」後面也可以直接接名詞：唯有他知道真相。
    唯有 can also take a noun: 唯有他知道真相.

常見錯誤

  • ✗ 唯有努力，就能成功。
    ✓ 唯有努力，才能成功。
    唯有和「才」搭配。
    唯有 pairs with 才.
  • ✗ 唯有他們都知道。
    ✓ 唯有他知道這件事。
    唯有表示「只有一個」，不和「都」搭配。
    唯有 means "only one"; not with 都.

例句

唯有彼此信任，合作才能長久。
Wéiyǒu bǐcǐ xìnrèn, hézuò cái néng chángjiǔ.
Only with mutual trust can cooperation last.
這條路很險，唯有老手才能過。
Zhè tiáo lù hěn xiǎn, wéiyǒu lǎo shǒu cái néng guo.
The path is dangerous; only the experienced can get through.
唯有親身經歷，才能真正體會。
Wéiyǒu qīnshēn jīnglì, cái néng zhēnzhèng tǐhuì.
Only through first-hand experience can one truly understand.
