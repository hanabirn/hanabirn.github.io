非但 ～，反而／而且 ～

非但：不但

非但 — not only (literary) — Chinese grammar, HSK 7–9

接續

非但 ＋ 不／沒 ＋ 預期的事，反而 ＋ 相反的結果；非但 ＋ A，而且 ＋ B
非但 + 不 / 沒 + the expected, 反而 + the opposite; 非但 + A, 而且 + B

說明

書面語的「不但」。常見的搭配是「非但不……反而……」：他非但不感謝，反而責怪我們。（他不但不感謝，反而怪我們。）

Literary 不但. Typical: 非但不…反而…: 他非但不感謝，反而責怪我們.

注意事項

  • 主詞相同時「非但」放主詞後；不同時放主詞前。
    Same subject: 非但 after it; different subjects: before.

常見錯誤

  • ✗ 他非但不幫忙，所以添亂。
    ✓ 他非但不幫忙，反而添亂。
    非但不……反而……。
    The pair is 非但不…反而….
  • ✗ 非但他很聰明，反而很努力。
    ✓ 他非但聰明，而且很努力。
    同方向遞進用「而且」。
    For "and also", use 而且.

例句

吃了藥，病非但沒好，反而更嚴重了。
Chī le yào, bìng fēidàn méi hǎo, fǎn'ér gèng yánzhòng le.
After the medicine, the illness didn’t improve but got worse.
這個方法非但省時，而且省錢。
Zhè ge fāngfǎ fēidàn shěng shí, érqiě shěng qián.
This method saves not only time but money.
批評非但沒讓他放棄，反而讓他更努力。
Pīpíng fēidàn méi ràng tā fàngqì, fǎn'ér ràng tā gèng nǔlì.
The criticism didn’t make him give up; it made him work harder.
