V/A-(으)ㄹ 테니까

我會～，所以（你）～；應該會～，所以～

I'll …, so (you) …; it'll probably …, so … — Korean grammar, Level 4

接續

沒有收音・ㄹ收音 → -ㄹ 테니까　有收音 → -을 테니까
no final consonant / ㄹ → -ㄹ 테니까　final consonant → -을 테니까

說明

1) 說話者表明自己要做的事，請對方據此行動：제가 청소할 테니까 쉬세요（我來打掃，你休息吧）。2) 推測某種情況，所以給對方建議：길이 막힐 테니까 지하철을 타세요（路應該會塞，搭地鐵吧）。後句常是命令或提議。

1) The speaker says what they will do, so the listener can act on it: 제가 청소할 테니까 쉬세요 (I'll clean, so you rest). 2) A guess gives a reason for advice: 길이 막힐 테니까 지하철을 타세요 (the roads will probably be busy, so take the subway). The second clause is usually a command or suggestion.

注意事項

  • 1) 的主語是「我」。
    In 1) the subject is "I".
  • 和「-(으)ㄹ 텐데」比：「텐데」帶出遺憾或委婉的建議；「테니까」是給對方一個理由。
    -(으)ㄹ 텐데 leads into regret or soft advice; -(으)ㄹ 테니까 gives the listener a reason.

常見錯誤

  • ✗ 제가 할게요니까 쉬세요.
    ✓ 제가 할 테니까 쉬세요.
    是「-(으)ㄹ 테니까」。
    It is -(으)ㄹ 테니까.
  • ✗ 길이 막히는 테니까 지하철을 타세요.
    ✓ 길이 막힐 테니까 지하철을 타세요.
    「테니까」前面用「-(으)ㄹ」。
    테니까 follows -(으)ㄹ.

例句

제가 청소할 테니까 좀 쉬세요.
我來打掃，你休息一下吧。
I'll clean up, so you take a rest.
길이 막힐 테니까 지하철을 타세요.
路應該會塞，請搭地鐵。
The roads will be busy, so take the subway.
곧 도착할 테니까 조금만 기다려 주세요.
我馬上就到，請再等一下。
I'll be there soon, so please wait a little.
