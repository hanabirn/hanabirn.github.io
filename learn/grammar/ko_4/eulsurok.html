V/A-(으)ㄹ수록

越～越～

the more …, the more … — Korean grammar, Level 4

接續

（-(으)면）＋ 語幹 ＋ (으)ㄹ수록：하면 할수록、보면 볼수록
(-(으)면) + stem + (으)ㄹ수록: 하면 할수록, 보면 볼수록

說明

前面的程度增加，後面也隨之變化：한국어는 공부하면 할수록 재미있어요（韓文越學越有趣）。前面的「-(으)면」可以省略：많을수록 좋아요（越多越好）。

As one thing increases, so does another: 한국어는 공부하면 할수록 재미있어요 (the more I study Korean, the more fun it gets). The -(으)면 part can be dropped: 많을수록 좋아요 (the more the better).

注意事項

  • 「수록」和前面的「ㄹ」連寫，不空格。
    Written without a space: 할수록.

常見錯誤

  • ✗ 공부하면 하을수록 재미있어요.
    ✓ 공부하면 할수록 재미있어요.
    無收尾音用「-ㄹ수록」。
    No 받침: -ㄹ수록.
  • ✗ 사람이 많으면 많는수록 좋아요.
    ✓ 사람이 많으면 많을수록 좋아요.
    有收尾音用「-을수록」。
    With 받침: -을수록.

例句

한국어는 공부하면 할수록 재미있어요.
韓文越學越有趣。
The more I study Korean, the more fun it gets.
그 노래는 들을수록 좋아요.
那首歌越聽越好聽。
That song gets better the more you listen.
친구는 많을수록 좋다고 생각해요.
我覺得朋友越多越好。
I think the more friends, the better.
