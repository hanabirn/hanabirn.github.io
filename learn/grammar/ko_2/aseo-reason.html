V/A-아서/어서（原因）

因為～所以～

because, so — Korean grammar, Level 2

接續

母音ㅏ・ㅗ → -아서　其他 → -어서　하다 → 해서　名詞 → 이라서/라서
ㅏ/ㅗ → -아서　others → -어서　하다 → 해서　nouns → 이라서/라서

說明

表示原因：배가 고파서 밥을 먹었어요（肚子餓所以吃飯了）、비가 와서 집에 있었어요（下雨所以待在家）。

Gives a reason: 배가 고파서 밥을 먹었어요 (I was hungry, so I ate), 비가 와서 집에 있었어요 (it rained, so I stayed in).

注意事項

  • 「-아서」後面不能接命令或邀請（×비가 와서 우산을 가져가세요），要改用「-(으)니까」（TOPIK 2）。
    -아서 can't be followed by a command or suggestion — use -(으)니까 for those.
  • 道歉、感謝常用：늦어서 죄송해요（遲到了很抱歉）、와 주셔서 감사합니다。
    Common in apologies and thanks: 늦어서 죄송해요, 와 주셔서 감사합니다.

常見錯誤

  • ✗ 비가 왔어서 집에 있었어요.
    ✓ 비가 와서 집에 있었어요.
    「-아서」前面不加過去式，時態放在最後。
    No past before -아서; the tense goes at the end.
  • ✗ 추워서 창문을 닫으세요.
    ✓ 추우니까 창문을 닫으세요.
    後面是請求時不能用「-아서」。
    A request after it needs -(으)니까, not -아서.

例句

배가 고파서 밥을 먹었어요.
肚子餓了，所以吃了飯。
I was hungry, so I ate.
비가 와서 집에 있었어요.
因為下雨，待在家裡。
It rained, so I stayed at home.
늦어서 죄송해요.
遲到了，很抱歉。
Sorry I'm late.
