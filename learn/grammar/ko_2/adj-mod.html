A-(으)ㄴ ＋ N

形容詞接名詞（～的～）

Adjective before a noun — Korean grammar, Level 2

接續

形容詞語幹沒有收尾音 ＋ ㄴ（예쁜 꽃）　有收尾音 ＋ 은（작은 가방）　있다/없다 ＋ 는（맛있는 음식）
adj stem without 받침 + ㄴ (예쁜 꽃)　with 받침 + 은 (작은 가방)　있다/없다 + 는 (맛있는 음식)

說明

形容詞放在名詞前面修飾它：예쁜 꽃（漂亮的花）、작은 가방（小包包）。「맛있다、재미있다」這類有「있다/없다」的用「는」：맛있는 음식（好吃的食物）。

To describe a noun, put the adjective in front: 예쁜 꽃 (a pretty flower), 작은 가방 (a small bag). Adjectives ending in 있다/없다 take 는: 맛있는 음식 (delicious food).

注意事項

  • 收尾音是ㅂ的形容詞會變：춥다 → 추운、덥다 → 더운。
    ㅂ adjectives change: 춥다 → 추운, 덥다 → 더운.
  • 收尾音是ㄹ的會脫落：길다 → 긴、멀다 → 먼。
    ㄹ drops: 길다 → 긴, 멀다 → 먼.

常見錯誤

  • ✗ 맛있은 음식
    ✓ 맛있는 음식
    有「있다」的形容詞用「는」。
    있다 adjectives take 는.
  • ✗ 춥은 날씨
    ✓ 추운 날씨
    「춥다」是ㅂ不規則，變成「추운」。
    춥다 is ㅂ-irregular: 추운.

例句

예쁜 꽃을 샀어요.
買了漂亮的花。
I bought a pretty flower.
맛있는 음식을 먹고 싶어요.
想吃好吃的東西。
I want to eat something delicious.
오늘은 추운 날씨예요.
今天是很冷的天氣。
It's cold weather today.
