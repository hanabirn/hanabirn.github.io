文法 › 韓文 2 級

-(으)ㄴ/는/(으)ㄹ 것 같다

好像～、應該是～（推測）

it seems …, I think … — Korean grammar, Level 2

接續

動詞：過去 -(으)ㄴ／現在 -는／未來 -(으)ㄹ ＋ 것 같다　／　形容詞：現在 -(으)ㄴ／未來 -(으)ㄹ ＋ 것 같다
verb: past -(으)ㄴ / present -는 / future -(으)ㄹ + 것 같다　/　adjective: present -(으)ㄴ / future -(으)ㄹ + 것 같다

說明

說出推測，或委婉地表達意見：밖에 비가 오는 것 같아요（外面好像在下雨）、이 옷이 더 예쁜 것 같아요（我覺得這件比較好看）。

A guess, or a softened opinion: 밖에 비가 오는 것 같아요 (it seems to be raining outside), 이 옷이 더 예쁜 것 같아요 (I think this one's prettier).

注意事項

  • 看到跡象的推測用「-는 것 같다」，沒有根據的預測用「-(으)ㄹ 것 같다」：비가 올 것 같아요（感覺會下雨）。
    -는 것 같다 is from what you see; -(으)ㄹ 것 같다 predicts: 비가 올 것 같아요.

常見錯誤

  • ✗ 이 옷이 더 예쁘는 것 같아요.
    ✓ 이 옷이 더 예쁜 것 같아요.
    形容詞現在用「-(으)ㄴ 것 같다」。
    Adjectives in the present take -(으)ㄴ.
  • ✗ 밖에 비가 와는 것 같아요.
    ✓ 밖에 비가 오는 것 같아요.
    「-는」直接接語幹。
    -는 goes straight on the stem.

例句

밖에 비가 오는 것 같아요.
外面好像在下雨。
It seems to be raining outside.
이 옷이 저한테 더 잘 어울리는 것 같아요.
我覺得這件比較適合我。
I think this one suits me better.
하늘이 흐려서 곧 눈이 올 것 같아요.
天陰陰的，好像快要下雪了。
The sky's grey — it looks like it'll snow soon.
