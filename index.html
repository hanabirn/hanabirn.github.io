✦ 教學手冊 ✦

🌐

切換語言

頁面頂部有8種語言的切換按鈕，可以隨時切換網站顯示語言。

📝

單字測驗

支援日文、韓文、法文、英文、中文五種單字測驗。

📖

錯題本

答錯的單字會自動記錄，可以專門複習。

📊

測驗統計

自動記錄每次測驗成績，顯示進步曲線。

🎵

音樂收藏

內嵌 Spotify 播放器，可切換「所有歌曲」和「中文/粵語歌」兩個播放清單。

🎮

osu! 收藏

輸入 Beatmap ID 或貼上 osu! 網址即可收藏。支援 Standard/Taiko/Catch/Mania 四種模式分類。點擊 ♡ 加入最愛，點擊 🎧 試聽，點擊 📋 複製 ID。

👤

關於我 + PP 查詢

顯示個人介紹和社群連結。底部的 osu! Profile Card 會自動載入個人數據。任何人也可以輸入自己的 osu! 用戶名或 ID 查詢四種模式的 PP 和總和。

💬

留言板

歡迎留下你的言語！留言會儲存在 Google 試算表中，所有訪客都能看到。

🌸

季節特效

右下角的按鈕可以切換春（樱花）、夏（萤火虫）、秋（枫叶）、冬（雪花）四種背景特效。

💿

BGM 唱片機

左下角的黑膠唱片可以播放 lo-fi 背景音樂。

🕐

時鐘＆天氣

右下角顯示即時時間、日期和你所在地的天氣。

✨

互動特效

點擊網頁任意處會爆出櫻花星星粒子特效。
